# 외부 의존성 지도

> 상태: `draft`
> 목적: 각 Bolt가 외부 확인·승인·도구에 의존하는 지점을 기록하고, 지연 시 보류·대체·재확인 방식을 정한다.

## 독립 용어 정의

- **Bolt**: 정적 학습 가이드의 하나 이상의 Unit을 작성·검토하고 완료 조건을 확인하는 작업 묶음이다.
- **외부 의존성**: 현재 저장소의 문서만으로 결정할 수 없어 외부 자료 접근, 사람의 승인 또는 외부 소유자의 응답이 필요한 항목이다.
- **승인 게이트**: 산출물을 다음 단계로 넘기기 전에 사용자가 결과를 보고 `Approve` 또는 `Request Changes`를 선택하는 확인 지점이다.
- **지연 대응**: 의존성이 제때 확인되지 않을 때 사실을 추측하지 않고 해당 주장·자료·Bolt를 보류하거나 범위를 명확히 하는 조치다.

## 의존성 요약

이 프로젝트에는 외부 API 호출, 외부 데이터 전달, 다른 개발팀의 구현 인계, AWS 계정·리소스·배포 환경이 없다. 실제로 관리할 의존성은 다음 네 범주다.

1. AWS Certification 공식 AIF-C01 시험 안내서 접근
2. AWS 공식 문서 페이지 접근
3. 사용자의 범위·계획·단계 승인
4. 정적 Markdown·CSV를 확인하는 저장소 로컬 도구와 뷰어의 가용성

## 외부 인계·데이터 경계

- **외부 API**: 없음. AWS 서비스 API를 호출하거나 자격 증명을 사용하지 않는다.
- **외부 데이터셋**: 없음. 학습자 답안·진도·개인정보를 수집하지 않는다.
- **다른 팀 인계**: 없음. 단일 작성자가 모든 문서 초안을 통합하고 역할별 검토는 저장소 안에서 수행한다.
- **AWS 계정·유료 실습**: 없음. 정적 Markdown·CSV만으로 학습 자료를 제공한다.
- **배포·운영**: 없음. 문서 품질 검사를 통과한 변경을 저장소에 통합하는 것이 전달 경계다.

## 지연 처리 순서

1. 지연된 URL·승인·검사 도구와 영향을 받는 Bolt를 식별한다.
2. 확인 가능한 사실과 확인하지 못한 주장을 문서·출처 상태로 분리한다.
3. 필요한 경우 해당 Bolt의 주장·문항·복습 자료를 보류하고, 확인되지 않은 내용을 `verified`로 표시하지 않는다.
4. 내부 링크·추적성·CSV 형식 문제는 수정 후 동일 검사를 다시 실행한다.
5. 범위·순서·보류 상태를 바꾸려면 사용자에게 선택지를 제시하고 승인 기록을 남긴다.

## Assumptions & Open Questions

- 공식 출처의 실제 접근 상태와 revision은 작성 시점에 확인한다.
- 사용자 승인까지 걸리는 시간은 고정하지 않으며, 승인 전에는 다음 단계로 전환하지 않는다.
- 외부 API·데이터·팀 인계가 없다는 결정은 현재 승인된 범위가 유지되는 것을 전제로 한다.
- 차단된 공식 출처의 대체 경로는 실제 URL과 내용이 확인된 뒤 결정한다.
