## 통합 요약

- 목적: AIF-C01 합격을 최우선으로 하면서 AI/ML과 AWS 완전 초보자가 개념 이해, AWS 서비스 선택, 기본 시나리오 판단, 문제 풀이까지 연결할 수 있는 한국어 가이드를 만든다.
- 대상: 코딩·수학·통계·모델 개발 경험이 없는 완전 초보자다.
- 범위: AIF-C01 공식 5개 도메인과 모든 작업·기술 항목을 포함한다.
- 산출물: D1~D5 도메인 문서, 100문항 이상 문제은행, 카드 요약, 진도표, 용어 퀴즈, UTF-8 Anki 앞면·뒷면 CSV, 출처·문서 추적표와 최종 품질 점검이다.
- 순서: `PU-00` 공식 기준선 뒤에 `PU-01`~`PU-05`를 D1→D5 순서로 작성하고, `PU-06` 추적표가 고아 항목 0개인지 확인한 뒤 `PU-07`~`PU-12`를 파생한다.
- 실무 확장: AWS 서비스의 개념·선택·비교·기본 시나리오까지만 포함하며, 공식 시험 범위와 `실무 확장`을 분리한다.
- 실행 가능성: 정적 Markdown·CSV 프로젝트로 조건부 실행 가능하며, 출처 최신성·접근 차단·범위 누락·문항 추적성을 통제한다.
