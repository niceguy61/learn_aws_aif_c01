# 역량 매트릭스

## 목적

이 매트릭스는 승인된 AIF-C01 학습 가이드를 완성하는 데 필요한 역량과 현재 확보 방식, 간극 및 완화책을 계획 수준에서 기록한다. 역량의 확보는 외부 채용이나 AWS Professional Services가 아니라 사용자와 Kiro/AIDLC 역할 지원을 기준으로 한다.

## 역할별 확보 범위

| 역할 | 확보 상태 | 담당 역량 | 제한 |
|---|---|---|---|
| 사용자 / Product Owner | 확보 | 범위·우선순위·공식 해석·최종 승인 | 사용자 승인 없이는 결정 확정 불가 |
| 단일 작성자 | 확보 | 문서 초안, 문제·카드·진도·Anki 작성과 수정 | 병렬 집필자 없음; 순차 계획 필요 |
| 제품·전달 역할 | Kiro/AIDLC 지원 | 학습 가치, 백로그, 의존성, 인계 | 제안만 가능하며 최종 결정권 없음 |
| 출처·규정 준수 역할 | Kiro/AIDLC 지원 | 공식 URL 조사, 최신성·시험/실무 구분 | 접근 차단 시 사실을 확정하지 않음 |
| 품질·디자인 역할 | Kiro/AIDLC 지원 | 초보자 관점, 구조, 문항·CSV·링크 QA | 사용자 승인 전 출시 불가 |
| 아키텍처·개발 역할 | Kiro/AIDLC 지원 | 안정 ID, 파일 구조, 형식 일관성 | 실행 애플리케이션·코드 구축은 범위 밖 |

## 역량 간극의 우선순위

1. **높음**: 공식 항목 누락과 출처 최신성 — `PU-00`과 `PU-06`을 D1 집필보다 먼저 또는 병행하여 통제한다.
2. **높음**: 초보자용 한국어 설명 — 각 도메인 작성 직후 품질·디자인 검토를 수행한다.
3. **높음**: 문제은행 추적성 — 문서와 항목 매핑이 확인되기 전에는 `PU-07`을 시작하지 않는다.
4. **중간**: CSV·Markdown 형식 오류 — `PU-11`과 `PU-12`에서 필드·인코딩·링크를 반복 확인한다.
5. **중간**: 단일 작성자 병목 — 작은 문서 단위와 D1→D5 순서를 유지하고, 논점별로만 Kiro/AIDLC 역할 검토를 호출한다.

## 추적성

이 매트릭스의 역량은 `scope-document.md`의 범위·품질 기준, `intent-backlog.md`의 `PU-00`~`PU-13`, `feasibility-assessment.md`의 출처·형식·데이터 제약, `AC-SCOPE-01`~`AC-SCOPE-09`에 연결된다. 범위 변경이나 새로운 역량 요구는 사용자 승인 후 영향받는 `PU`, 문서, 출처와 완료 기준을 함께 갱신한다.
