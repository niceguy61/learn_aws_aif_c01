# RAID Log

## 목적

이 문서는 AIF-C01 한국어 학습 가이드의 feasibility 단계에서 확인한 위험(Risks), 가정(Assumptions), 이슈(Issues), 의존성(Dependencies)을 관리한다. 위험은 아직 발생하지 않은 가능성, 이슈는 현재 확인된 장애, 의존성은 외부 조건으로 구분한다. [scope]

## RAID Summary and Escalation Rules

- **즉시 중단:** 시험 범위의 공식 기준을 확인할 수 없거나, 확인되지 않은 사실을 확정해야만 문서를 작성할 수 있는 경우. [Q2][scope]
- **수정 후 진행:** 문항에 출처 URL, 정답, 해설, 도메인 또는 작업·기술 항목이 누락된 경우. [Q3][Q9]
- **범위 조정:** 실무 확장이 시험 핵심 복습을 밀어내거나 사용자가 애플리케이션·데이터 수집을 추가하려는 경우. [Q4][Q5][Q10]
- **유지보수 시작:** 사용자가 변경을 요청하면 영향 문서와 관련 출처·문항을 다시 확인한다. [Q6][Q11]
