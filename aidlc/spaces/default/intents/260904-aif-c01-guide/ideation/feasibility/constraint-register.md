# Constraint Register

## Purpose

이 문서는 승인된 AIF-C01 한국어 학습 가이드의 실행을 제한하거나 품질에 영향을 주는 조건을 등록한다. 시험 범위와 실무 확장을 분리하며, 결정 근거가 있는 항목에는 원래 질문·의도 기록의 태그를 붙인다. [scope][Q10]

## Constraints

| C-08 | Anki 자료는 UTF-8 CSV이며 기본 필드는 앞면과 뒷면이다. | 산출물 형식 | 높음 | [Q4] | CSV 인코딩·구분자·필드 순서를 확인하고 가져오기 설명을 제공한다. |
| C-09 | 모든 학습 자료와 검토 자료는 한국어로 작성하되 AWS 서비스명·API·CLI·URL은 원문을 보존한다. | 언어 | 높음 | 승인된 의도 및 대화 언어 | 전문 용어 최초 등장 시 영어를 병기하고 문단 설명은 한국어로 작성한다. |

| C-11 | 학습자 개인정보·결제정보·건강정보 또는 규제 대상 데이터를 수집·저장하지 않는다. | 데이터·규제 | 매우 높음 | [Q5] | 계정, 답안 저장, 식별자, 결제, 건강정보 입력 기능을 추가하지 않는다. |
| C-12 | 유지보수는 초기 완성 후 사용자가 변경을 요청할 때 시작한다. | 운영 | 중간 | [Q6][Q11] | 문서별 확인일을 기록하고 요청이 오면 변경된 출처와 영향 문서를 재검토한다. |
| C-13 | 시험일의 정확한 날짜를 알 수 없으므로 “1개월 이내”를 상대 일정으로 취급한다. | 일정 불확실성 | 중간 | [Q4] | 달력 기반 계획을 확정하지 않고 단계별 우선순위와 완료 조건으로 관리한다. |
| C-14 | 출처를 통째로 복사하지 않고 공식 자료를 바탕으로 한국어 학습 내용으로 재구성한다. | 출처·저작권 | 높음 | [Q5] 및 source-research 규칙 | 짧은 인용만 허용하고 URL·제목·확인일을 기록한다. |

## Scope Boundaries

### 포함

- 공식 AIF-C01 시험 범위의 5개 도메인 전체
- 초보자를 위한 AI/ML·GenAI·파운데이션 모델·책임 있는 AI·보안·거버넌스 설명
- AWS 서비스의 개념, 선택 기준, 유사 서비스 비교, 기본 시나리오
- 100문항 이상 문제은행, 문항별 출처 URL, 카드·퀴즈·진도 자료
- UTF-8 CSV Anki 자료(앞면·뒷면)

### 명시적 제외

- 모델 직접 개발, 학습, 복잡한 수학·통계 증명, 하이퍼파라미터 최적화
- 프로덕션 서비스, 파이프라인, API, 데이터베이스 및 AWS 인프라 구축
- 유료 AWS 계정 실습
- 학습자 개인정보·결제정보·건강정보의 수집·저장
- 자동 정기 최신성 모니터링
- 공식 시험 범위로 확인되지 않은 내용을 출제 범위로 표현 [Q5][Q6][Q8][Q10][Q11]

## Constraint Acceptance Criteria

- [ ] 기준 목록의 각 공식 항목이 적어도 하나의 학습 문서 또는 `해당 없음/확장` 기록에 연결된다.
- [ ] 5개 도메인마다 공식 출처와 확인일이 기록된다.
- [ ] 확인되지 않은 출처의 주장이 `확인 필요`로 표시되어 확정 콘텐츠에 섞이지 않는다.
- [ ] 문제은행이 100문항 이상이고 모든 문항에 필수 메타데이터와 공식 URL이 있다.
- [ ] Anki CSV가 UTF-8이며 앞면·뒷면 필드를 제공한다.
- [ ] 시험 범위와 실무 확장이 문서·추적표에서 구분된다.
- [ ] 개인정보·규제 대상 데이터를 다루는 기능이나 원문이 추가되지 않는다.
- [ ] 최종 검토에서 전체 링크를 재확인하고 확인일을 갱신한다. [Q1][Q2][Q3][Q4][Q5]

## Assumptions & Open Questions

### Assumptions

- 문서 편집·링크 확인·표 기반 추적이 가능한 작업 환경을 사용한다. [scope]
- 사용자가 변경 요청을 할 때 최신성 검토에 필요한 범위와 대상 문서를 지정할 수 있다. [Q6][Q11]
