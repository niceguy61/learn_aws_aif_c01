# Feasibility Questions

이 질문지는 승인된 의도에서 이미 결정된 범위·언어·대상·학습 방식·실무 확장 경계를 다시 묻지 않습니다. 문서 규모, 출처 추적성, 규제 전제, 유지 가능성에 영향을 주는 미해결 사항만 확인합니다.

## Q1. AWS 공식 출처의 최신성 기준을 어느 수준으로 운영할까요?

AIF-C01 공식 시험 안내서와 AWS 서비스 문서는 변경될 수 있으므로, 검증 시점을 정해야 `source_checked`와 `verified` 상태를 일관되게 관리할 수 있습니다. 1개월 이내 준비라는 일정과 D1부터 D5까지 순차 작성 방식을 함께 고려해 선택해 주세요. [Q4][Q5][Q7]

- A. 각 도메인 문서를 작성하기 직전에 관련 공식 출처를 확인하고, 최종 검토 때 전체 링크를 다시 확인한다.
- B. 집필 시작 시 전체 출처를 확인하고, 최종 검토 때 전체 링크와 시험 안내서를 다시 확인한다.
- C. 최종 검토 때 전체 출처를 확인하고, AWS 공식 시험 안내서 또는 핵심 서비스 문서의 변경이 알려진 경우에만 추가 확인한다.
- D. 확인 주기를 별도로 정하지 않고 문서마다 확인 날짜만 기록한다.
- X. Other (please specify)

[Answer]: A

## Q2. 공식 페이지가 동적이거나 접근이 차단될 때 어떤 진행 기준을 적용할까요?

출처 링크를 열 수 없으면 사실을 추측하지 않고 `blocked` 상태로 남겨야 합니다. 다만 5개 도메인을 1개월 일정 안에 완성하려면 대체 공식 출처를 사용할지, 해당 항목을 보류할지 기준이 필요합니다. [Q5][scope]

- A. 원래 URL은 `blocked`로 기록하고, 같은 사실을 확인할 수 있는 다른 AWS 공식 문서로 대체한 뒤 대체 이유와 두 링크를 함께 기록한다.
- B. 원래 URL이 확인될 때까지 해당 주장과 문서를 `확인 필요`로 보류한다.
- C. 시험 범위에 직접 연결되는 항목은 AWS Certification 공식 페이지를 우선 대체 출처로 사용하고, 서비스 세부사항은 확인 전까지 문서에 넣지 않는다.
- X. Other (please specify)

[Answer]: B

## Q3. 100문항 이상 문제은행의 문항별 추적성 수준을 어디까지 요구할까요?

문항 수가 많아질수록 도메인 누락과 오래된 설명을 발견하기 어려워집니다. 문항 제작과 검토 비용 사이의 균형을 정해야 전체 정답률 80%라는 성공 기준을 해석할 수 있습니다. [Q3][Q9]

- A. 모든 문항에 도메인, 작업·기술 항목, 정답, 해설, 관련 공식 출처 URL을 기록한다.
- B. 모든 문항에 도메인, 정답, 해설을 기록하고 공식 출처 URL은 문항 묶음 단위로 연결한다.
- C. 모든 문항에 도메인과 정답·해설을 기록하며, 출처 URL은 도메인 문서에서만 추적한다.
- X. Other (please specify)

[Answer]: A

## Q4. Anki 가져오기 자료의 기본 형식을 무엇으로 확정할까요?

Anki 산출물은 내용 자체뿐 아니라 가져오기 설정과 호환되는 형식이 필요합니다. 카드 요약과 중복되지 않도록 최소 필드를 정해야 합니다. [Q3]

- A. UTF-8 TSV 파일 하나를 제공하고, 앞면과 뒷면을 기본 필드로 사용한다.
- B. UTF-8 CSV 파일 하나를 제공하고, 앞면과 뒷면을 기본 필드로 사용한다.
- C. UTF-8 TSV와 CSV를 모두 제공하고, 앞면·뒷면·도메인 태그 필드를 포함한다.
- X. Other (please specify)

[Answer]: B

## Q5. 이 가이드 저장소가 학습자의 개인정보 또는 규제 대상 데이터를 다루지 않는다는 전제를 확정할까요?

현재 의도는 Markdown 학습 자료를 만드는 작업이며 애플리케이션, 사용자 계정, 유료 실습, 학습자 데이터 수집은 포함하지 않습니다. 이 전제가 맞아야 HIPAA, PCI DSS, GDPR 등 서비스 운영 규제 검토를 문서 콘텐츠의 출처·저작권·품질 관리 검토와 분리할 수 있습니다. [Q2][Q8][Q10]

- A. 학습자 개인정보·결제정보·건강정보를 수집하거나 저장하지 않으며, 규제 검토는 문서 출처와 배포 시 주의사항 수준으로 제한한다.
- B. 향후 학습자 답안·진도·식별자를 저장할 가능성이 있으므로 개인정보 처리와 보존 요구사항을 별도 범위로 기록한다.
- C. 조직 또는 고객의 규제 대상 자료를 참고 문서로 포함할 수 있으므로 자료별 데이터 분류와 사용 허가를 확인한다.
- X. Other (please specify)

[Answer]: A

## Q6. 첫 산출물 이후 공식 범위와 서비스 문서의 유지보수 시작 조건을 어떻게 정할까요?

시험 안내서와 AWS 서비스 기능은 바뀔 수 있으므로, 유지보수 조건이 없으면 `verified` 문서가 빠르게 오래될 수 있습니다. 별도 문서 관리자 없이 사용자의 품질 요구사항으로 운영한다는 결정과 충돌하지 않는 기준을 선택해 주세요. [Q5][Q11]

- A. AWS Certification 공식 시험 안내서가 변경되거나 시험 범위 변경이 확인될 때 전체 추적표와 관련 문서를 재검토한다.
- B. 시험 안내서 변경 여부와 관계없이 월 1회 전체 링크·최신성 검토를 수행한다.
- C. 분기별 전체 검토를 기본으로 하고, 공식 변경이 확인되면 즉시 관련 문서만 재검토한다.
- D. 초기 완성 후 유지보수 주기는 정하지 않고, 사용자가 변경을 요청할 때만 검토한다.
- X. Other (please specify)

[Answer]: D
