# Feasibility Assessment

## Executive Summary

이 작업은 AWS Certified AI Practitioner(AIF-C01) 시험을 준비하는 완전 초보자를 위한 한국어 Markdown 학습 가이드와 보조 학습 자료를 만드는 문서 프로젝트다. AWS 계정, 실행형 애플리케이션, 학습자 데이터 저장소를 만들지 않으므로 기술적 실행 가능성은 높다. 다만 5개 도메인 전체, 100문항 이상의 문항별 추적성, 카드·진도 자료까지 함께 제공하려면 범위 누락과 출처 최신성 관리가 핵심 위험이다. [scope][Q3][Q9]

판정은 **조건부 실행 가능(Proceed with controls)** 이다. 다음 통제 조건을 지키면 진행을 막는 기술적·규제적 장애는 확인되지 않았다.

- AIF-C01 공식 시험 안내서의 5개 도메인과 모든 작업·기술 항목을 기준 목록으로 사용한다. [scope][Q3]
- 각 도메인 문서 작성 직전에 관련 AWS 공식 출처를 확인하고, 최종 검토에서 전체 링크와 시험 안내서를 다시 확인한다. [Q1]
- 공식 페이지가 동적이거나 접근되지 않으면 주장을 추측하지 않고 `확인 필요`로 보류한다. [Q2]
- 문제마다 도메인, 작업·기술 항목, 정답, 해설, 공식 출처 URL을 기록한다. [Q3]
- Anki 산출물은 UTF-8 CSV이며 기본 필드는 앞면과 뒷면이다. [Q4]
- 학습자 개인정보·결제정보·건강정보 및 규제 대상 데이터를 수집하거나 저장하지 않는다. [Q5]
- 초기 완성 뒤 정기 검토는 자동으로 약속하지 않고, 사용자의 변경 요청이 있을 때 유지보수를 시작한다. [Q6][Q11]

## Scope and Evaluation Basis

### 시험 범위

시험 범위는 다음 5개 도메인 전체와 공식 시험 안내서가 지정한 작업·기술 항목이다.

1. AI 및 ML의 기초 — 20%
2. GenAI의 기초 — 24%
3. 파운데이션 모델의 적용 — 28%
4. 책임 있는 AI에 대한 가이드라인 — 14%
5. AI 솔루션의 보안, 규정 준수 및 거버넌스 — 14%

이 비율과 항목은 시험 출제 범위를 설명하는 기준이며, 공식 시험 안내서에 없는 내용을 시험 출제 범위라고 단정하지 않는다. [scope]

### 실무 확장

실무 확장은 시험 개념을 AWS 서비스가 무엇인지, 언제 선택하는지, 비슷한 서비스와 어떻게 구분하는지, 기본 시나리오에서 어떤 단서로 판단하는지로 연결하는 수준이다. 복잡한 모델 개발, 운영 파이프라인 구축, 유료 AWS 실습은 기본 범위에 포함하지 않는다. [Q8][Q10]

### 산출물 품질 기준

- 도메인별 README와 개념 단위 Markdown 문서
- 시험 범위와 실무 확장을 구분한 문서 추적표
- 100문항 이상 자체 문제은행
- 문항별 공식 출처 URL과 도메인·작업·기술 항목 연결
- 카드 요약, 학습 진도표, 용어 퀴즈
- UTF-8 CSV Anki 자료(앞면·뒷면)
- 초보자용 용어 설명, 비교표, 시나리오, 오개념 교정, 확인 질문 [Q3][Q4][Q9]

### 핵심 실행 흐름

1. AIF-C01 공식 시험 안내서에서 도메인·작업·기술 기준 목록을 확정한다. [scope]
2. 공식 사이드바와 도메인별 출처를 등록하고, 각 도메인 집필 직전에 확인한다. [Q1]
3. 승인된 목차와 추적표에 따라 D1부터 D5 순서로 문서를 작성한다. [Q7]
4. 문서 내용을 바탕으로 문항·카드·퀴즈를 만들고 각 문항에 출처 URL을 연결한다. [Q3][Q4]
5. 최종 검토에서 링크, 시험 범위 누락, 실무 확장 경계, 초보자 설명, 100문항 이상 문항 추적성을 점검한다. [Q1][Q3][Q9][Q10]

## Technical and Organizational Viability

이 프로젝트는 실행 코드나 AWS 리소스를 변경하지 않는 정적 문서 작업이므로 런타임 장애, 배포 환경, AWS 계정 권한 문제는 현재 범위의 선행 조건이 아니다. 핵심 작업은 출처 수집, 한국어 재구성, 추적표 관리, 문항 검토이며 문서 편집과 링크 확인으로 수행할 수 있다. [scope]

조직적 제약은 별도 문서 관리자나 정기 유지보수 담당자를 전제로 하지 않는다는 점이다. 따라서 `verified` 표시는 확인 시점의 결과로 이해하고, 사용자 변경 요청이 들어오면 관련 문서만 영향 분석 후 재검토한다. [Q6][Q11]

## Regulatory and Data Considerations

현재 산출물은 정적 학습 자료이며 학습자의 개인정보·결제정보·건강정보를 수집하거나 저장하지 않는다. 그러므로 애플리케이션 운영을 전제로 한 HIPAA, PCI DSS, GDPR 등의 세부 통제는 현재 feasibility 범위가 아니다. 다만 외부 자료를 그대로 복제하지 않고 공식 출처를 연결해 재구성하며, 배포 시 출처·저작권·품질 주의를 유지한다. [Q5]

데이터 수집, 사용자 계정, 답안 저장, 결제, 건강정보, 조직의 규제 대상 원문을 추가하면 이 판정은 더 이상 자동으로 적용되지 않으며 별도의 규제·보안 검토가 필요하다.

## Assumptions & Open Questions

### Assumptions

- 이 작업은 정적 Markdown 학습 자료, 추적표, 문제은행, 카드 자료를 저장하는 문서 프로젝트이며 실행형 학습 애플리케이션과 통합하지 않는다. [scope]
- 시험일은 상대적인 “1개월 이내”로 취급하며 정확한 달력 날짜를 전제하지 않는다. [Q4]
- 공식 시험 안내서와 AWS 공식 문서는 사실 판단의 우선 출처다. [scope][Q1]
- 사용자가 변경을 요청하기 전까지 정기적인 전체 유지보수는 수행하지 않는다. [Q6][Q11]

### Open Questions

None.

답변된 feasibility 질문의 통합 요약은 `feasibility-questions.md`에 보존되어 있으며, 사용자가 `Looks correct`로 확인했다. 이 단계에서 추가 질문은 만들지 않는다.

## Explicit Out of Scope

다음 항목은 현재 AIF-C01 학습 가이드의 기본 범위에 포함하지 않는다.

- 모델을 직접 개발하거나 학습시키는 구현
- 복잡한 수학 증명, 통계 유도, 하이퍼파라미터 최적화
- 프로덕션 AI/ML 파이프라인, 애플리케이션, API, 데이터베이스 구축
- AWS 계정 생성, 인프라 배포, 유료 AWS 실습
- 학습자 계정, 답안·진도 저장, 개인정보·결제정보·건강정보 수집
- 조직 또는 고객의 규제 대상 원문을 참고 문서로 저장
- 공식 시험 안내서에 없는 내용을 공식 출제 범위라고 단정하는 것
- 자동화된 정기 최신성 모니터링과 사용자 요청 전의 전체 재작성 [Q5][Q6][Q8][Q10][Q11]

## Feasibility Conclusion

5개 도메인 전체와 100문항 이상의 추적 가능한 문제은행·카드 자료를 만드는 일은 문서 중심 작업으로서 실행 가능하다. 성공 조건은 범위를 넓히는 것이 아니라 기준 목록과 문항별 출처 추적을 지키고, 확인되지 않은 사실을 보류하며, 시험 범위와 실무 확장을 분리하는 것이다. [scope][Q2][Q3][Q9][Q10]

현재 확인된 차단 요소는 없고, 주요 위험은 출처 변경·접근 차단·문항 검토량·초보자 설명의 누락이다. 이 위험은 constraint register와 RAID log의 통제로 관리한다. 산출물은 표준 승인 게이트에서 검토를 받아야 다음 단계로 진행할 수 있다.

이 판정은 feasibility 질문의 통합 요약이 확인된 뒤 작성된 현재 문서 상태를 기준으로 한다.
