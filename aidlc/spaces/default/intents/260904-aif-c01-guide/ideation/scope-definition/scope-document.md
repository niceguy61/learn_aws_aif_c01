# 범위 정의 문서

## 목적과 상위 근거

이 문서는 AIF-C01 시험을 준비하는 AI/ML·AWS 완전 초보자를 위한 한국어 학습 가이드의 범위 경계, 우선순위, 순서와 완료 기준을 확정한다. 범위는 승인된 `intent-statement.md`, `feasibility-assessment.md`, `constraint-register.md`를 바탕으로 하며, 공식 시험 범위와 실무 확장을 섞지 않는다.

### 상위 승인 결정

- 공식 AIF-C01의 5개 도메인과 모든 작업·기술 항목을 다룬다.
- 대상은 코딩·수학·통계·모델 개발 경험이 없는 완전 초보자다.
- 시험 합격을 우선하며 준비 기간은 정확한 날짜가 아닌 “1개월 이내”의 상대 일정으로 관리한다.
- D1에서 D5로 순서대로 작성하고 각 도메인 문서를 검토한다.
- 100문항 이상의 자체 문제은행, 카드 요약, 진도표, 용어 퀴즈, UTF-8 Anki CSV를 제공한다.
- AWS 서비스의 개념·선택·비교·기본 시나리오까지만 실무 확장으로 다룬다.

## 범위 결정 원칙

1. **시험 범위 우선**: 공식 시험 안내서에 정의된 항목을 기준 목록으로 삼고, 공식 안내서에 없는 내용은 시험 출제 범위라고 표현하지 않는다.
2. **초보자 접근성**: 핵심 용어는 최초 등장 시 영어를 병기하고, 선수 지식·쉬운 말·생활 예시를 함께 제공한다.
3. **추적 가능성**: 도메인, 작업·기술 항목, 학습 문서, 문제, 카드와 출처를 안정적인 ID로 연결한다.
4. **최신성 통제**: 변할 수 있는 서비스 기능·모델명·요금·리전·할당량은 작성 직전과 최종 검토 시 공식 출처를 확인한다.
5. **작은 단위 집필**: 한 문서가 하나의 핵심 개념을 설명하도록 나누고, 문서 간 연결을 표시한다.
6. **시험과 실무의 명시적 구분**: 모든 확장 설명에 `실무 확장` 표지를 붙여 공식 시험 범위와 구별한다.

## 포함 범위

### 학습 콘텐츠

- D1 `AI 및 ML의 기초` — 채점 콘텐츠 20%
- D2 `GenAI의 기초` — 채점 콘텐츠 24%
- D3 `파운데이션 모델의 적용` — 채점 콘텐츠 28%
- D4 `책임 있는 AI에 대한 가이드라인` — 채점 콘텐츠 14%
- D5 `AI 솔루션의 보안, 규정 준수 및 거버넌스` — 채점 콘텐츠 14%
- 각 도메인의 공식 작업·기술 항목을 문서 또는 명시적인 `해당 없음/확장` 기록으로 연결
- 개념 설명, AWS 서비스 선택 기준, 유사 개념·서비스 비교, 기본 시나리오, 시험 판단 단서, 오해 교정, 확인 질문
- 도메인별 `README.md`, 개념 단위 Markdown, 누적 용어 사전

### 평가·지원 자료

- 문항별 도메인·작업/기술 항목·정답·해설·공식 URL을 갖춘 100문항 이상 문제은행
- 핵심 개념 카드 요약과 용어 퀴즈
- 1개월 이내 학습을 위한 진도표와 복습 순서
- 앞면·뒷면 필드를 갖춘 UTF-8 CSV Anki 자료와 가져오기 안내
- 최종 누락·출처·초보자 관점·시험/실무 구분 점검 기록

## 제외 범위

다음 항목은 이번 학습 가이드의 기본 범위에 포함하지 않는다.

- 모델을 직접 개발·학습하거나 하이퍼파라미터를 최적화하는 구현
- 복잡한 수학 증명, 통계 유도 또는 모델 내부 수식의 심화 증명
- 프로덕션 AI/ML 파이프라인, 애플리케이션, API, 데이터베이스, 인프라 구축
- AWS 계정 생성, 유료 AWS 실습 또는 실습 비용을 요구하는 활동
- 학습자 계정, 답안·진도 저장, 개인정보·결제정보·건강정보 수집
- 자동화된 정기 최신성 모니터링과 사용자 변경 요청 전의 전체 재작성
- 공식 시험 안내서에서 출제 범위로 확인되지 않은 주제의 시험 출제 단정

`Could Have` 항목은 이번 승인 범위에서 별도로 약속하지 않는다. 추가 예시나 심화 읽을거리는 위 Must/Should 산출물이 완료된 뒤에만 변경 요청으로 검토한다.

## 가치 흐름과 D1→D5 순서

| 순서 | 도메인 단계 | 학습자 가치 | 다음 단계로 넘기는 기준 |
|---|---|---|---|
| 1 | D1 AI 및 ML의 기초 | AI, ML, 학습 유형, 데이터와 평가의 기본 언어를 익힌다. | 공식 D1 항목별 문서 연결과 기초 용어 점검이 완료된다. |
| 2 | D2 GenAI의 기초 | 생성형 AI, 토큰, 임베딩, 프롬프트, 생성 과정의 기본 판단을 익힌다. | D2 항목별 설명·비교·확인 질문과 출처가 완료된다. |
| 3 | D3 파운데이션 모델의 적용 | 사용 사례에 맞는 모델 적용, 프롬프트와 확장 방식을 비교한다. | D3 항목별 서비스 선택 단서와 실무 확장이 분리된다. |
| 4 | D4 책임 있는 AI에 대한 가이드라인 | 편향, 공정성, 투명성, 설명 가능성, 안전한 사용의 판단 기준을 익힌다. | D4 항목별 오해 교정·시나리오·출처가 완료된다. |
| 5 | D5 보안·규정 준수·거버넌스 | AI 솔루션의 데이터·접근·위험·규정 준수 관점에서 선택한다. | D5 항목별 통제 개념과 시험/실무 구분이 완료된다. |

## 시험 범위와 실무 확장의 분리

| 구분 | 포함 내용 | 표현 규칙 | 출처 기준 |
|---|---|---|---|
| 시험 범위 | 공식 시험 안내서의 5개 도메인, 작업·기술 항목, 채점 비율 | `시험 범위` 표지와 공식 항목 ID를 사용한다. | AWS Certification 공식 시험 안내서 |
| 실무 확장 | AWS 서비스가 무엇인지, 언제 선택하는지, 유사 서비스와 구분하는 법, 기본 시나리오 | `실무 확장` 표지로 별도 구획하고 시험 공식 범위로 단정하지 않는다. | 관련 AWS 공식 서비스 문서·백서·공식 교육 자료 |
| 학습 해설 | 초보자를 위한 비유, 오개념 교정, 복습 질문 | 원문 사실과 학습자 해설을 구분한다. | 사실은 공식 출처, 해설은 자체 구성 |

실무 확장이 시험 범위 항목을 설명하는 경우에도 원래 시험 항목 ID를 먼저 표시한다. 출처가 동적이거나 차단되어 사실을 확인하지 못한 경우에는 내용을 확정하지 않고 `확인 필요`로 표시한다.

## 공식 출처와 추적성 통제

1. `sources/aws-sidebar-index.md`에 공식 사이드바 링크를 누락 없이 등록한다.
2. `sources/source-registry.yaml`에 URL, 제목, 출처 유형, 상위 주제, 주 도메인·보조 도메인, 연결 문서, 확인일, 상태를 기록한다.
3. 링크 상태는 `discovered → downloaded → summarized → reviewed → verified`로 관리하며, 차단된 링크는 `blocked`와 사유를 남긴다.
4. 문서 front matter의 `source_urls`와 `source_checked`를 작성하고, 문서 끝에 제목·URL·확인일을 다시 기록한다.
5. 시험 범위 기준과 실무 확장 출처의 성격을 구분한다. 공식 출제 범위 판정은 AWS Certification 공식 페이지에만 의존한다.
6. 문제은행 필수 필드는 `문항 ID`, `도메인`, `작업/기술 항목`, `정답`, `해설`, `공식 출처 URL`이다.
7. 최종 점검에서 각 공식 항목이 학습 문서 또는 `해당 없음/확장` 기록으로 연결되는지, 각 문항 URL과 출처 상태가 유효한지 확인한다.
8. 원문을 통째로 복사하지 않고 한국어 학습 목적에 맞게 재구성하며, 필요한 짧은 인용만 링크와 함께 사용한다.

| AC-SCOPE-09 | 공식 시험 날짜를 발명하지 않고 “1개월 이내” 상대 일정과 우선순위로 학습 계획을 표현한다. | 진도표와 문서 표현 검토 |

## 미해결 항목과 변경 통제

현재 승인된 범위에 영향을 주는 미해결 질문은 없다. 이후 공식 페이지가 차단되거나 변경되면 해당 주장·문항을 확정하지 않고 원 URL, 차단 사유, 영향 문서와 후속 확인 대상을 기록한다. 사용자가 범위 변경을 요청하기 전에는 자동으로 범위를 넓히거나 전체 자료를 재작성하지 않는다.

범위 변경이 필요하면 영향받는 도메인, 문제, 카드, 추적표와 완료 기준을 먼저 확인하고 별도 사용자 승인을 받은 뒤 반영한다.
