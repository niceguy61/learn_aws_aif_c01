# 정적 Markdown 학습 가이드 학습자 문서 흐름

## 흐름 상태와 목적

- 상태: 초안
- 대상: AI·ML과 AWS를 처음 접하는 완전 초보자
- 시작점: `docs/00-start-here/`
- 기본 방향: D1 → D2 → D3 → D4 → D5
- 지원 경로: 용어 사전, 문제은행, 카드, 용어 퀴즈, 진도표, Anki CSV
- 추적 대상: PU-00~PU-13, AC-SCOPE-01~AC-SCOPE-09

이 문서는 사용자가 웹 애플리케이션의 화면을 조작하는 흐름이 아니라 Markdown 파일 사이를 읽고 링크로 이동하는 흐름을 정의한다. 상태 저장이나 자동화가 없으므로 학습자는 진도와 오답을 문서 또는 인쇄물에 수동으로 표시한다.

## 흐름 표기

```text
[문서] --링크 선택--> [다음 문서]
[문서] --오답 회귀--> [원 개념 문서]
[문서] --출처 확인--> [공식 출처 목록]
[문서] --확인 필요--> [보류·후속 확인 기록]
```

각 흐름 단계는 다음 네 가지를 설명한다.

1. 현재 문서와 학습 목적
2. 학습자가 선택하는 명확한 링크
3. 다음 문서에서 기대하는 변화
4. 문제가 생겼을 때의 회복 경로

## 흐름 1: 처음 시작해 학습 진입점 찾기

**대상:** 완전 초보자  
**시작 조건:** 가이드 저장소를 처음 열었거나 학습 방법을 모르는 상태  
**성공 결과:** 선수 지식과 D1 첫 문서로 이동하고 상대 진도표를 이해한다.

1. `docs/00-start-here/README.md`에서 가이드 목적과 대상 설명을 읽는다.
2. `선수 지식과 학습 진단` 링크를 선택한다.
3. 자신의 경험을 개인정보 없이 수동으로 확인한다.
   - AI·AWS 용어가 낯설다 → `docs/00-start-here/prerequisites.md`를 읽고 D1 시작으로 이동한다.
   - 기본 용어는 안다 → `docs/00-start-here/diagnostic.md`의 질문을 풀고 필요한 D1 개념으로 이동한다.
   - D1 복습이 필요하다 → `docs/01-ai-ml-foundations/README.md`의 복습 경로로 이동한다.
4. `1개월 이내 진도표`를 열어 D1~D5와 문제 풀이 순서를 확인한다.
5. `D1 AI 및 ML의 기초 시작하기` 링크를 선택한다.
6. D1 README에서 첫 개념 문서와 해당 공식 시험 항목을 확인한다.

**회복 경로**

- 시작 문서를 찾지 못하면 저장소 루트의 `docs/00-start-here/`를 직접 연다.
- 선수 지식이 부족하면 D1 개념 문서의 `선수 지식` 링크를 따라가고, 이해가 안 되는 용어는 `docs/glossary.md`에서 먼저 찾는다.
- 진도표의 정확한 시험 날짜를 요구하지 않는다. 일정은 `1개월 이내` 상대 표현으로 유지한다.

## 흐름 2: 도메인 허브에서 개념 문서 읽기

**대상:** D1~D5를 순서대로 학습하는 초보자  
**시작 조건:** 현재 도메인 README에 도착한 상태  
**성공 결과:** 공식 항목에 연결된 개념을 이해하고 다음 개념으로 이동한다.

1. 도메인 README의 도메인 이름과 채점 비중을 확인한다.
2. `시험 범위` 구획에서 공식 작업·기술 항목의 목록을 확인한다.
3. 학습 지도 또는 순서 있는 문서 목록에서 첫 개념 문서를 선택한다.
4. 개념 문서의 `이 문서에서 배울 것`과 `선수 지식`을 먼저 읽는다.
5. 쉬운 설명, AWS 관점, 비교, 시나리오 순서로 읽는다.
6. `시험에서 판단하는 단서`에서 문제의 핵심 표현과 서비스 선택 기준을 확인한다.
7. `스스로 답하는 확인 질문`에 답한 뒤 `docs/glossary.md`에서 새 용어를 복습한다.
8. `다음 문서` 링크를 선택하거나 현재 개념에 대한 문제를 푼다.

**회복 경로**

- 선수 지식이 부족하면 이전 문서 링크로 돌아간다.
- 용어가 낯설면 용어 사전의 정의와 첫 등장 문서로 이동한다.
- 개념 문서에 `확인 필요`가 있으면 해당 주장을 정답 근거로 사용하지 않고 출처 원장과 후속 확인 기록을 확인한다.

## 흐름 3: D1에서 D5로 이동하기

```text
시작 안내
   ↓
D1 AI 및 ML의 기초
   ↓  기초 용어와 데이터·평가 확인
D2 GenAI의 기초
   ↓  생성형 AI·토큰·임베딩·프롬프트 연결
D3 파운데이션 모델의 적용
   ↓  사용 사례·모델 적용·확장 방식 판단
D4 책임 있는 AI에 대한 가이드라인
   ↓  편향·공정성·투명성·설명 가능성 판단
D5 보안·규정 준수·거버넌스
   ↓
통합 문제·카드·퀴즈·오답 복습
```

ASCII 흐름의 텍스트 대체 설명: 학습자는 시작 안내에서 D1로 들어가 기초 언어를 익힌다. D1의 선수 지식은 D2의 GenAI 개념으로 이어지고, D2는 D3의 파운데이션 모델 적용 판단을 준비한다. D4는 AI를 책임 있게 평가하는 기준을 추가하고, D5는 데이터·접근·위험·규정 준수 관점에서 전체 판단을 마무리한다.

### 도메인 인계 규칙

| 전환 | 이전 단계에서 확인할 것 | 다음 단계의 입구 |
|---|---|---|
| D1 → D2 | AI·ML·데이터·평가 기본 용어 | D2의 생성형 AI와 관련 용어 |
| D2 → D3 | 토큰, 임베딩, 프롬프트, 생성 과정 | 모델 적용과 사용 사례 문서 |
| D3 → D4 | 모델 선택과 적용의 기본 판단 | 책임 있는 사용과 위험 문서 |
| D4 → D5 | 편향·공정성·투명성·설명 가능성 | 보안·규정 준수·거버넌스 문서 |
| D5 → 통합 복습 | 통제·위험·출처 판단 | 문제은행과 오답 회귀 |

## 흐름 4: 개념에서 용어 사전으로 복습하기

**대상:** 새 영어 용어를 만난 학습자  
**시작 조건:** 개념 문서에서 핵심 용어를 처음 만난 상태  
**성공 결과:** 용어의 쉬운 정의와 첫 등장·연결 문서를 확인한다.

1. 개념 문서에서 최초 등장한 영어 용어와 한국어 설명을 확인한다.
2. `docs/glossary.md`의 해당 용어 링크를 선택한다.
3. 용어의 한 줄 정의, 혼동하기 쉬운 용어, 첫 등장 문서를 읽는다.
4. `원 개념 문서로 돌아가기` 링크를 선택한다.
5. 용어 퀴즈나 카드 요약으로 기억을 확인한다.

**회복 경로**

- 용어가 사전에 없으면 해당 문서를 `확인 필요` 대상으로 표시하고 임의의 정의를 추가하지 않는다.
- 같은 용어가 여러 도메인에서 다르게 쓰이면 도메인별 설명과 출처를 함께 표시한다.

## 흐름 5: 문제를 풀고 원 개념으로 회귀하기

**대상:** 개념 학습을 마친 학습자  
**시작 조건:** 문제은행 또는 도메인 README의 문제 링크 선택  
**성공 결과:** 정답·해설·출처를 확인하고 필요한 개념을 다시 학습한다.

1. 문제의 문항 ID, 도메인, 작업·기술 항목을 확인한다.
2. 문제를 먼저 풀고 정답을 보기 전에 자신의 선택을 수동으로 기록한다.
3. 정답과 해설을 확인한다.
4. 해설의 `원 개념 문서` 링크를 선택한다.
5. 오답이면 해당 개념의 비교표·시험 판단 단서를 다시 읽는다.
6. 관련 용어를 `docs/glossary.md`와 카드에서 복습한다.
7. 진도표에 복습 완료 또는 재학습 필요를 수동으로 표시한다.
8. 같은 항목의 다른 문제를 다시 풀어 판단을 확인한다.

**문제은행의 필수 표시**

```text
문항 ID → 도메인 → 작업·기술 항목 → 정답 → 해설
       → 원 개념 문서 → 공식 출처 URL·제목·확인일·상태
```

**회복 경로**

- 문항에 공식 URL이 없으면 해당 문항을 확정 문제로 사용하지 않고 `확인 필요`로 표시한다.
- 정답 해설과 개념 문서가 모순되면 문서의 최신 상태와 공식 출처 원장을 우선 확인하고, 해결 전까지 문항을 보류한다.
- 색상이나 정답 기호만으로 맞고 틀림을 표시하지 않고 `정답`, `오답`, `재학습 필요` 텍스트를 사용한다.

## 흐름 6: 시험 범위와 실무 확장을 구분하기

**대상:** AWS 서비스 선택 설명을 읽는 학습자  
**시작 조건:** 개념 문서의 서비스 또는 시나리오 구획에 도착한 상태  
**성공 결과:** 시험에서 외워야 할 공식 항목과 실무 이해를 위한 보강 내용을 혼동하지 않는다.

1. 문서의 `시험 범위` 제목을 먼저 읽는다.
2. 해당 설명에 공식 시험 항목 ID가 있는지 확인한다.
3. `실무 확장` 제목으로 이동할 때는 이 내용이 시험 공식 범위인지 자동으로 가정하지 않는다.
4. AWS 서비스의 목적, 선택 시점, 유사 서비스와의 차이를 읽는다.
5. 서비스 기능·모델명·요금·리전·할당량처럼 변할 수 있는 내용은 출처 확인일과 상태를 확인한다.
6. `확인 필요` 표시가 있으면 출처 원장 또는 후속 확인 기록을 통해 재검증한다.

**회복 경로**

- 하나의 표에 시험 범위와 실무 확장이 섞여 있으면 구획을 나누어 읽고, 문서 검토 대상으로 기록한다.
- 공식 시험 안내서에 없는 실무 내용은 시험 출제 범위라고 표현하지 않는다.

## 흐름 7: 출처와 추적성 확인하기

**대상:** 사실의 근거 또는 문서 누락을 확인하려는 학습자와 검토자  
**시작 조건:** 개념 문서, 문제, 카드의 출처 링크 선택  
**성공 결과:** 공식 URL, 제목, 확인일, 상태와 연결된 문서·항목을 확인한다.

1. 현재 문서의 `출처` 섹션에서 URL, 문서 제목, 확인일을 확인한다.
2. 출처의 상태가 `discovered`, `downloaded`, `summarized`, `reviewed`, `verified` 중 어디인지 본다.
3. 공식 시험 범위 판단은 AWS Certification 공식 시험 안내서 링크로 확인한다.
4. 서비스 설명은 관련 AWS 공식 문서 또는 공식 자료 링크로 확인한다.
5. `sources/aws-sidebar-index.md`에서 사이드바의 상위 주제와 연결 문서를 확인한다.
6. `sources/source-registry.yaml`에서 도메인, 문서, 상태 연결을 확인한다.

**회복 경로**

- 페이지가 동적이거나 차단되면 URL과 차단 사유를 기록하고 내용을 만들어내지 않는다.
- 서로 다른 공식 문서의 표현이 다르면 두 링크와 차이를 함께 기록한다.
- 확인일이 없거나 오래된 정보는 `verified`로 표시하지 않는다.

## 흐름 8: 모바일과 접근성 기준으로 읽기

**대상:** 모바일 사용자, 키보드 사용자, 화면 낭독기 사용자  
**시작 조건:** 어떤 Markdown 문서든 열려 있는 상태  
**성공 결과:** 기기나 입력 방법과 관계없이 현재 위치, 핵심 내용, 다음 링크를 찾는다.

1. 제목과 현재 도메인을 먼저 확인한다.
2. 제목 탐색 또는 목차로 원하는 구획으로 이동한다.
3. 링크 텍스트만 읽어도 이동 목적을 이해한다.
4. 표가 화면 폭을 넘으면 표 아래의 목록형 대체 설명을 읽는다.
5. 시험 범위·실무 확장·확인 필요를 텍스트 표지로 구분한다.
6. 다음 문서 또는 이전 문서 링크로 이동한다.

**문서 수준 접근성 기준**

- 한 문서에 `h1` 하나를 두고 논리적 `h2`, `h3` 순서를 유지한다.
- Markdown의 기본 링크와 목록을 우선하여 키보드 탐색을 보장한다.
- ASCII 구조도와 비교표에는 즉시 이해할 수 있는 텍스트 설명을 붙인다.
- 색상만으로 상태·정답·범위를 표시하지 않는다.
- 모바일 폭에서는 문단을 짧게 유지하고 비교표 열 수를 줄인다.
- 긴 제목, 긴 URL, 긴 코드 줄은 줄바꿈 가능한 형태로 작성한다.
- 접기 문법을 사용하더라도 접힌 상태에서 핵심 결론과 대체 링크가 사라지지 않게 한다.

## 문서 실패·경계 상태

정적 문서에는 애플리케이션의 로딩 상태가 없으므로, 다음의 문서 상태를 명시적으로 다룬다.

| 상태 | 학습자에게 보이는 표시 | 회복 경로 |
|---|---|---|
| 문서 없음 | `문서 링크 확인 필요` | 상위 README와 저장소 경로 확인 |
| 출처 차단 | `확인 필요: 출처 접근 차단` | 원 URL·사유·대체 공식 출처 기록 |
| 미검증 내용 | `상태: draft` 또는 `review` | 공식 출처 확인 전 문제 확정 금지 |
| 긴 표 | `모바일 대체 목록` | 표 아래 목록형 설명 읽기 |
| 고아 시험 항목 | `추적성 누락` | PU-06 추적표에서 문서 연결 추가 |
| 문제 메타데이터 누락 | `문항 보류` | 문항 ID·항목·정답·해설·출처 보완 |
| 시험·실무 혼합 | `분류 검토 필요` | 두 구획과 표현을 분리 |
| 용어 고아 | `용어 연결 필요` | 첫 등장 문서·다음 문서 링크 추가 |
