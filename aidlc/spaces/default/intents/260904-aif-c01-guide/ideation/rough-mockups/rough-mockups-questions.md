# Rough Mockups 확인 질문

## 단계 목적

이 문서는 애플리케이션 화면을 설계하는 문서가 아니다. 정적 한국어 Markdown 학습 가이드에서 학습자가 문서에 들어와 다음 학습 자료와 문제 풀이로 이동하는 경로를 확인하기 위한 문서 탐색·학습 흐름 초안이다.

## 승인된 결정 반영

다음 항목은 앞 단계에서 이미 결정되었으므로 다시 묻지 않는다.

- 대상: AI/ML과 AWS를 처음 접하는 완전 초보자
- 목표: 1개월 이내 AIF-C01 합격 준비와 개념 이해
- 범위: AIF-C01의 D1~D5 전체와 모든 공식 작업·기술 항목
- 작성 순서: D1 → D2 → D3 → D4 → D5
- 산출물: 도메인 문서, 공식 출처 추적, 100문항 이상 문제은행, 카드, 진도표, 용어 퀴즈, UTF-8 Anki CSV
- 제외: 애플리케이션, 로그인, 학습자 데이터 저장, 개인정보 수집, 유료 AWS 실습, 코드·모델 개발·복잡한 수학 증명·프로덕션 구축
- 문서 방식: UTF-8 Markdown, 작은 개념 단위, 모바일에서 읽기 쉬운 구조
- 표현 원칙: `시험 범위`와 `실무 확장`을 명시적으로 구분

## 질문 항목별 결정 및 가정

### 주요 진입점과 문서 단위

- 진입점은 `docs/00-start-here/`다.
- 시작 문서는 사용법, 선수 지식, 학습 진단, 1개월 이내 진도표를 안내한다.
- 각 도메인은 `README.md`를 허브로 사용한다.
- 도메인 README에서 개념 단위 문서, `docs/glossary.md`, 관련 문제·카드·퀴즈·Anki 자료로 연결한다.

### 핵심 학습 흐름

- 기본 흐름은 `docs/00-start-here/` → 도메인 README → 개념 단위 문서 → 용어 사전 → 확인 질문·문제은행이다.
- 도메인은 D1에서 D5로 순차 이동하되, 용어 사전과 이전 도메인 링크를 통해 필요한 복습을 허용한다.
- 각 개념 문서는 설명 후 AWS 서비스 선택 단서, 비교, 실무 확장, 시험 판단 단서, 확인 질문을 제공한다.
- 문제를 푼 뒤 오답은 원 개념 문서와 용어 사전으로 되돌아가며, 진도표에서 복습 상태를 수동으로 표시한다.

### 정보 계층

1. 현재 문서의 제목과 학습 목표
2. 선수 지식과 한 줄 요약
3. 핵심 개념 설명
4. 시험 범위와 실무 확장 구획
5. 비교·시나리오·시험 판단 단서
6. 오해·핵심 정리·확인 질문
7. 다음 문서와 공식 출처

### 시각 디자인과 상호작용 가정

- 브랜드 시스템이나 별도 UI 컴포넌트는 사용하지 않는다.
- Markdown의 제목, 목록, 표, 인용, 코드 블록, 명확한 링크 텍스트만 사용한다.
- 화면 전환·모달·자동 저장·검색 앱·로그인은 정의하지 않는다.
- 링크는 목적을 드러내는 텍스트를 사용하고, 현재 위치는 제목·상위 문서 링크·다음 문서 링크로 확인한다.

### 기기와 반응형 가정

- 모바일 우선으로 작성한다.
- 긴 문단 대신 짧은 문단과 목록을 사용하고, 비교표는 열 수를 제한한다.
- 표가 모바일에서 넘칠 수 있으면 같은 정보를 짧은 목록으로도 설명한다.
- 데스크톱에서는 문서 목차와 본문을 함께 확인할 수 있지만, 특정 화면 배치나 고정 사이드바를 요구하지 않는다.
- 독자는 브라우저·Markdown 뷰어의 기본 키보드 이동과 링크 활성화를 사용한다.

### 접근성 가정

- 문서마다 하나의 `h1`을 두고 `h2`와 `h3`를 논리적 순서로 사용한다.
- 문서 뷰어의 `header`, `nav`, `main`, `aside`, `footer` 영역이 있다면 의미에 맞게 사용하고, 그렇지 않으면 제목과 링크 계층으로 동일한 구조를 제공한다.
- 첫 본문 링크는 `본문으로 건너뛰기`를 지원하는 뷰어에서 사용할 수 있도록 문서 구조를 방해하지 않는 명확한 제목·목차 순서로 둔다.
- 키보드만으로 제목 탐색, 링크 이동, 접기 기능이 가능한 Markdown 뷰어를 우선한다. 접기 기능을 쓰더라도 키보드 대체 경로를 제공한다.
- 링크 목적을 링크 텍스트에 쓰며 `여기`와 같은 모호한 표현을 피한다.
- 색상만으로 시험 범위·실무 확장·정답 상태를 구분하지 않고 텍스트 표지와 기호를 함께 사용한다.
- 쉬운 한국어를 우선하고 처음 나오는 핵심 용어에는 영어를 병기한다.

## 모순 분석

현재 상위 승인 문서와 정적 Markdown 가이드 조건 사이에 해결되지 않은 모순은 없다.

- 화면 설계 조건은 문서 탐색 설계로 변환한다.
- 사용자 계정·진도 저장 요구는 없으므로 진도표는 학습자가 로컬 파일이나 인쇄물에서 수동으로 표시하는 문서다.
- 모바일 가독성은 반응형 애플리케이션 구현이 아니라 문단·표·링크 구조의 제약으로 다룬다.
- 출처 추적성은 앱의 실시간 기능이 아니라 `sources/` 인벤토리, 문서의 출처 섹션, PU·AC ID 연결로 노출한다.
