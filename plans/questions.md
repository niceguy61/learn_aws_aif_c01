## 답변 해석 및 목차 수정 기준

- 목표 우선순위: `A → C → B` — 합격을 최우선으로 하되, 장기적으로 AI/ML과 AWS를 배우는 교재이며 실무 입문에도 사용할 수 있게 한다.
- 학습자: AI/ML과 AWS 모두 처음인 완전 초보자.
- 일정: 1개월 이내 시험을 가정한 집중 학습 구조. 주당 1~3시간이므로 핵심 요약과 반복 복습을 우선하고, 실무 확장은 별도 표시한다.
- 설명: 초보자 상세 설명, 실무 확장, 심화 읽을거리까지 제공한다.
- 코드·수학·실습: 코드와 수학 중심 설명 및 유료 AWS 실습은 기본 범위에서 제외한다.
- 문제: 전체 100문항 이상의 자체 제작 문제은행을 목표로 한다. 단일 선택과 복수 응답을 우선하며, 공식 시험 문제를 복제하지 않는다. 문항 형식은 AWS 공식 안내서의 실제 정의를 최종 기준으로 재확인한다.
- 최신성: 시험 범위와 2026년 현재 AWS 기능을 분리해서 표시한다.
- 서비스: 공식 도메인 페이지에 명시된 서비스 중심으로 다룬다.
- 원문: 접근 가능한 공식 Markdown/PDF를 `sources/raw/`에 보관하고, 별도의 한국어 재구성 요약본을 작성한다.
- 산출물: 저장소에서 읽는 Markdown을 기본으로 한다.
- 문체: 존댓말 기반의 친절한 교재이며, 표·ASCII 다이어그램·시나리오를 적극 사용한다.
- 검토: D1부터 도메인 하나씩 작성하고 승인받는다.
- AI-DLC: 먼저 `/aidlc compose`의 맞춤 workflow 제안을 확인한다. depth는 `Comprehensive`, test strategy는 `Standard`를 제안한다.
- 학습 보조: 카드형 요약, 학습 진도표, 용어 퀴즈, Anki 가져오기용 자료를 포함한다.

## Anki란 무엇인가

Anki는 간격 반복(spaced repetition) 방식으로 암기 카드를 복습하는 애플리케이션이다. 이 프로젝트에서는 핵심 용어·서비스 비교·한 문장 암기 포인트를 CSV 또는 탭으로 구분한 파일로 제공해 Anki에 가져올 수 있게 한다. Anki 사용을 원하지 않는 학습자도 Markdown 카드로 그대로 읽을 수 있게 한다.
