# 문서 메타데이터 배지

이 디렉터리의 SVG는 학습 문서 상단에 표시하는 저장소 로컬 메타데이터 배지입니다.

- 외부 이미지 서비스나 네트워크 요청에 의존하지 않습니다.
- 각 배지는 도메인, 난이도, 문서 상태를 한 줄로 표시합니다.
- SVG는 `role="img"`, `title`, `desc`를 제공하고, 문서의 `<img>`에는 같은 의미의 `alt` 텍스트를 제공합니다.
- 공식 시험 범위나 AWS 기능을 설명하는 자료가 아니며, 문서 탐색을 위한 UI 보조 요소입니다.
