# AIF-C01 가이드 제품 원칙

## 프로젝트 목적
이 저장소는 AWS Certified AI Practitioner(AIF-C01) 자격증을 준비하는 AI/ML 입문자를 위한 완전한 한국어 학습 가이드다. 단순 암기 자료가 아니라, 개념 이해 → AWS 서비스 선택 → 시나리오 판단 → 시험 문제 적용까지 이어지는 학습 경험을 제공한다.

## 주 대상
- AI, ML, 생성형 AI를 처음 접하는 학습자
- AWS 핵심 서비스 경험이 없거나 제한적인 학습자
- 코딩·수학·통계·모델 개발 경험이 없어도 따라올 수 있어야 하는 학습자

## 공식 범위
반드시 AWS 공식 AIF-C01 시험 안내서의 다음 5개 도메인을 빠짐없이 다룬다.
1. AI 및 ML의 기초 — 채점 콘텐츠 20%
2. GenAI의 기초 — 채점 콘텐츠 24%
3. 파운데이션 모델의 적용 — 채점 콘텐츠 28%
4. 책임 있는 AI에 대한 가이드라인 — 채점 콘텐츠 14%
5. AI 솔루션의 보안, 규정 준수 및 거버넌스 — 채점 콘텐츠 14%

공식 시험 안내서가 정의하지 않은 내용을 시험 출제 범위인 것처럼 단정하지 않는다. 시험 범위와 실무 확장 내용을 명확히 구분한다.

## 필수 성공 기준
- 모든 도메인, 작업, 기술 항목을 추적 가능한 형태로 다룬다.
- 각 핵심 용어를 처음 보는 학습자가 이해할 수 있도록 선수 지식과 쉬운 예시부터 설명한다.
- AWS 서비스는 "무엇인지", "언제 쓰는지", "무엇과 구분하는지", "시험에서 어떤 단서로 고르는지"를 함께 설명한다.
- 개념 설명, 비교표, 시나리오, 오개념 교정, 복습 질문, 미니 퀴즈가 서로 연결된다.
- 모든 외부 사실에는 원문 출처 URL과 확인일을 남긴다.
- 불확실하거나 최신성 확인이 필요한 내용은 추측하지 않고 `확인 필요`로 표시한다.

## 언어와 질문 규칙
- 모든 사용자 질문, 확인 질문, 요구사항 질문지, 진행 안내와 설명은 항상 한글로 작성한다.
- 코드 식별자, AWS 서비스명, API명, CLI 명령, URL, 공식 문서 제목은 원문 표기를 보존한다.
- 학습 문서는 한국어를 기본으로 하되 핵심 영어 용어를 최초 등장 시 병기한다.
- 사용자의 결정이 필요한 경우 한 번에 답할 수 있는 번호 매긴 한글 질문으로 묻고, 질문 없이 임의의 범위·난이도·시험일을 확정하지 않는다.

## 범위 밖 작업
이 프로젝트는 AIF-C01 합격을 위한 이해와 판단을 목표로 한다. 모델을 직접 개발하거나, 복잡한 수학 증명·하이퍼파라미터 최적화·프로덕션 파이프라인 구축을 요구하지 않는다. 그런 내용은 선택적 심화 자료로만 분리한다.
