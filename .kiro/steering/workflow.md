# 작업 진행 방식

## 단계 순서
1. 공식 범위와 사이드바 링크를 조사한다.
2. 조사 결과를 바탕으로 전체 목차와 문서 추적표 초안을 만든다.
3. 사용자에게 한글 질문지를 제시하고 범위·난이도·학습 방식·산출물 선호를 확인한다.
4. 답변과 승인된 목차를 AI-DLC workflow의 단계별 산출물로 기록한다.
5. 도메인별 Markdown을 작은 단위로 작성한다.
6. 출처 검증, 초보자 관점 검토, 도메인 누락 검사를 거친다.

## 사용자 승인 게이트
- 목차, 학습 기간, 문제 수, 코드 실습 여부, 최신성 기준처럼 결과에 큰 영향을 주는 사항은 질문으로 확인한다.
- 질문은 항상 한글로 작성하고, 선택지와 자유 응답을 함께 제공한다.
- 사용자가 답하기 전에는 `초안`, `제안`, `확인 필요` 상태를 유지한다.
- 사용자의 답변을 받으면 질문지와 결정 사항을 `plans/questions.md`에 기록한다.

## AI-DLC 연계
- AI-DLC가 제공하는 단계·승인 게이트·메모리·감사 기록을 따르되, AIF-C01 문서의 교육 품질 기준은 이 steering과 공식 출처가 결정한다.
- AI-DLC 생성 파일을 수정할 때는 해당 파일의 목적과 기존 규칙을 먼저 확인한다.
- AI-DLC 상태 파일과 학습 콘텐츠를 섞지 않는다.
- 각 단계가 끝날 때 결과물, 미해결 질문, 출처 검증 상태를 짧게 기록한다.
