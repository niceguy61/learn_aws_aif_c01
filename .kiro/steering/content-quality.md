# 초보자 대상 콘텐츠 품질 규칙

## 설명의 깊이
- 전문 용어를 정의하지 않고 사용하지 않는다.
- 정의만 제시하지 말고 직관적 비유, 작은 예시, AWS 사용 맥락을 차례로 제시한다.
- 학습자가 헷갈리는 지점을 먼저 예상해 `왜 이것이 아닌가`까지 설명한다.
- 수식이 꼭 필요한 경우 기호를 먼저 풀어 쓰고, 시험에 필요한 직관을 먼저 설명한다.
- 초보자에게 필요한 AWS 기초(IAM, S3, EC2, Lambda, 리전, 가용 영역, 요금, 공동 책임 모델)를 적절한 시점에 연결한다.

## 시험 대비 품질
각 핵심 주제에는 다음을 포함한다.
- 출제 가능성을 과장하지 않는 범위 표시
- 문제에서 찾아야 할 단서
- 정답을 고르는 사고 순서
- 헷갈리는 선택지와 틀린 이유
- 한 문장 암기 포인트
- 최소 2개의 자기 점검 질문

## 정확성 검토
- 모델명·서비스 기능·통합 가능 여부·보안 기능·요금 관련 문장은 AWS 공식 출처로 확인한다.
- 서비스가 비슷해 보여도 사용 사례, 입력·출력, 관리 주체, 비용 모델, 보안 경계를 비교한다.
- 최신 기능과 시험 범위를 동일시하지 않는다. `시험 핵심`, `AWS 실무 확장`, `추가 읽기`로 구분한다.
- 사실, 해석, 학습 팁을 문장 수준에서 구분한다.

## 금지 사항
- 출처 없는 숫자, 성능 수치, 요금, 시험 문항 예측을 작성하지 않는다.
- 공식 시험 문제를 복원하거나 유출 자료처럼 제시하지 않는다.
- 초보자에게 필요하지 않은 코드 중심 설명으로 핵심 개념을 가리지 않는다.
- 한글 질문을 영어로 작성하지 않는다.
