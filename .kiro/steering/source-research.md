# 공식 자료 조사와 변환 규칙

## 조사 기준
- AIF-C01 공식 시험 안내서의 주제·도메인·작업·기술 항목을 기준 목록으로 삼는다.
- 사이드바 링크는 링크 자체를 생략하지 않고 `sources/aws-sidebar-index.md`와 `sources/source-registry.yaml`에 등록한다.
- AWS 문서, AWS Skill Builder, AWS 공식 블로그 등 출처의 성격을 구분한다. 공식 시험 범위를 정하는 근거는 AWS Certification 공식 페이지로 제한한다.
- 페이지를 확인할 때 제목, URL, 상위 주제, 관련 도메인, 확인일, 접근 상태를 기록한다.

## 다운로드·요약 원칙
- 사용자가 요청한 자료 수집은 학습에 필요한 공식 자료를 식별하고, 원문 보존이 허용되는 범위에서 메타데이터·링크·짧은 인용을 저장하는 방식으로 수행한다.
- 원문 전체를 그대로 재배포하지 않고, 각 도메인 Markdown은 출처를 바탕으로 새롭게 구성한 한국어 설명과 학습 예시로 작성한다.
- 자동 추출 결과는 초안일 뿐이다. 제목·목록·표·코드·경고문이 올바르게 변환되었는지 확인한 뒤 `reviewed`로 바꾼다.
- 출처 페이지가 동적이거나 접근이 차단되면 실패 사실과 URL을 기록하고, 다른 공식 출처로 대체할 때 그 이유를 남긴다.

## 도메인 매핑
각 출처와 문서는 다음 중 하나 이상으로 매핑한다.
- `D1`: AI 및 ML의 기초
- `D2`: GenAI의 기초
- `D3`: 파운데이션 모델의 적용
- `D4`: 책임 있는 AI에 대한 가이드라인
- `D5`: AI 솔루션의 보안, 규정 준수 및 거버넌스
- `FOUNDATION`: 모든 도메인의 선수 AWS 지식
- `EXAM`: 문제 유형·학습법·시험 운영

하나의 자료가 여러 도메인에 걸치면 주 도메인과 보조 도메인을 모두 표시한다.

## 검증 체크리스트
- [ ] 공식 URL과 문서 제목이 기록되어 있다.
- [ ] 확인 날짜가 기록되어 있다.
- [ ] 원문 사실과 학습자의 이해를 돕는 해설이 구분되어 있다.
- [ ] AIF-C01 시험 범위와 실무 확장 내용이 구분되어 있다.
- [ ] 관련 도메인·학습 문서·용어 사전으로 연결된다.
- [ ] 링크가 끊겼거나 내용이 변한 경우 상태와 후속 조치가 기록되어 있다.
