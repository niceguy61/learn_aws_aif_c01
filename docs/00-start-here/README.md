# AIF-C01 한국어 가이드 시작하기

## 이 문서에서 배울 것

이 가이드는 AWS Certified AI Practitioner(AIF-C01)를 처음 준비하는 학습자가 AI·ML·GenAI의 기본 개념을 이해하고, AWS 서비스와 사용 사례를 연결하며, 시험 시나리오를 판단할 수 있도록 돕습니다. [출처: AWS Certified AI Practitioner(AIF-C01) 시험 안내서](https://docs.aws.amazon.com/ko_kr/aws-certification/latest/ai-practitioner-01/ai-practitioner-01.html)

## 학습 순서

1. [D1 — AI 및 ML의 기초](../01-ai-ml-foundations/README.md)
2. [D2 — GenAI의 기초](../02-generative-ai/README.md)
3. [D3 — 파운데이션 모델의 적용](../03-foundation-models/README.md)
4. D4 — 책임 있는 AI

D1에서 기본 용어와 학습 유형을 잡은 뒤 D2와 D3로 이동하면, 생성형 AI와 파운데이션 모델을 처음 접할 때 새로운 용어를 앞 문서와 연결할 수 있습니다.

## 문서 읽는 방법

각 문서는 다음 순서로 읽습니다.

- **시험 핵심**: 공식 시험 범위와 직접 연결되는 내용
- **초보자 설명**: 처음 보는 용어를 비유와 예시로 설명한 내용
- **AWS 실무 확장**: 시험 범위를 넘어 실제 서비스 선택에 도움이 되는 내용
- **시험에서 판단하는 단서**: 문제의 조건에서 먼저 찾을 표현
- **복습 카드와 확인 질문**: 짧은 반복 복습용 내용

시험 핵심과 AWS 실무 확장은 같은 내용으로 취급하지 않습니다. AWS 서비스나 기능은 변할 수 있으므로, 문서의 확인 날짜와 출처 링크를 함께 확인합니다.

## 1개월 집중 학습 기본 루프

```text
개념 읽기 → 비교표 복습 → 시나리오 판단 → 확인 질문 → 문제은행 복습
```

주당 학습 시간이 짧다면 한 번에 많은 문서를 읽기보다, 한 문서를 읽은 뒤 핵심 카드를 소리 내어 설명하고 다음 날 확인 질문을 다시 푸는 방식으로 진행합니다.

## 이 가이드의 범위

- AIF-C01 공식 시험 안내서의 5개 도메인을 기준으로 합니다.
- 코드 작성, 복잡한 수학 증명, 유료 AWS 실습은 기본 학습 경로에 포함하지 않습니다.
- 실제 시험 문항을 복제하지 않고, 개념과 시나리오를 확인하는 자체 문제를 작성합니다.
