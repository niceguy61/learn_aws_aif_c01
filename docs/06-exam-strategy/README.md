# 시험 전략과 문제은행

## 목적

이 디렉터리는 공식 시험 문항을 복제하지 않고, 공식 범위에서 학습한 개념을 시나리오에 적용하는 자체 문제와 복습 전략을 관리합니다.

## 현재 문서

- [D1 자체 문제은행](d1-question-bank.md)
- [D2 자체 문제은행](d2-question-bank.md)
- [D3 자체 문제은행](d3-question-bank.md)
- D1 용어 퀴즈와 복습 카드는 [D1 디렉터리](../01-ai-ml-foundations/README.md)에서 연결합니다.
- D2 용어 퀴즈와 복습 카드는 [D2 디렉터리](../02-generative-ai/README.md)에서 연결합니다.
- D3 용어 퀴즈와 복습 카드는 [D3 디렉터리](../03-foundation-models/README.md)에서 연결합니다.

## 문제 작성 원칙

- 공식 시험 문제나 유출 문제를 재현하지 않습니다.
- 문항마다 관련 도메인과 연결 문서를 기록합니다.
- 정답만 제시하지 않고 선택지를 판단하는 단서를 설명합니다.
- 단일 선택과 복수 응답을 구분합니다.
- 공식 시험 범위와 실무 확장 내용을 섞어 단정하지 않습니다.
