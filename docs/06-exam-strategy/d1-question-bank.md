# D1 자체 문제은행

> 이 문서는 공식 시험 문제가 아닙니다. AIF-C01 D1 개념을 시나리오에 적용하는 연습을 위해 새로 작성한 문제입니다.

## 문제

### Q1 — 단일 선택

한 팀이 고객 이메일을 `환불`, `배송`, `제품 문의` 중 하나로 자동 분류하려고 합니다. 가장 적절한 문제 유형은 무엇인가요?

- A. 회귀
- B. 분류
- C. 클러스터링
- D. 강화 학습

**정답:** B

**해설:** 결과가 미리 정해진 범주 중 하나이므로 분류 문제입니다. [D1 문서: AI 사용 사례와 기법 선택](../01-ai-ml-foundations/03-ai-use-cases-and-technique-selection.md)

### Q2 — 단일 선택

과거 판매량을 이용해 다음 달 판매량이라는 숫자를 예측하려고 합니다. 어떤 접근 방식이 가장 가까운가요?

- A. 회귀
- B. 분류
- C. 클러스터링
- D. 음성 인식

**정답:** A

**해설:** 연속적인 숫자 값을 예측하므로 회귀에 가깝습니다. [D1 문서: 데이터 유형과 학습 유형](../01-ai-ml-foundations/02-data-and-learning-types.md)

### Q3 — 단일 선택

레이블이 없는 고객 구매 기록에서 비슷한 행동을 하는 고객 그룹을 찾으려고 합니다. 어떤 작업을 우선 고려하나요?

- A. 분류
- B. 회귀
- C. 클러스터링
- D. 지도 학습만 가능

**정답:** C

**해설:** 레이블 없이 유사한 데이터를 묶는 작업은 클러스터링입니다. [D1 문서: 데이터 유형과 학습 유형](../01-ai-ml-foundations/02-data-and-learning-types.md)

### Q4 — 단일 선택

에이전트가 환경에서 행동을 선택하고, 결과에 따라 보상 또는 불이익을 받습니다. 어떤 학습 방식의 단서인가요?

- A. 지도 학습
- B. 비지도 학습
- C. 강화 학습
- D. 회귀

**정답:** C

**해설:** 행동과 그 결과의 보상 피드백은 강화 학습의 핵심 단서입니다. [D1 문서: 데이터 유형과 학습 유형](../01-ai-ml-foundations/02-data-and-learning-types.md)

### Q5 — 단일 선택

다음 중 GenAI 사용 사례에 가장 가까운 것은 무엇인가요?

- A. 거래가 사기인지 정상인지 분류
- B. 다음 달 수요량 예측
- C. 고객 문의에 대한 답변 초안 생성
- D. 고객을 구매 패턴별로 그룹화

**정답:** C

**해설:** 새로운 답변 콘텐츠를 만드는 작업은 생성형 AI 사용 사례에 가깝습니다. [D1 문서: AI·ML·GenAI의 관계](../01-ai-ml-foundations/01-ai-ml-genai-relationship.md)

### Q6 — 단일 선택

음성 녹음을 텍스트로 변환해야 합니다. 연결되는 AWS 서비스는 무엇인가요?

- A. Amazon Polly
- B. Amazon Translate
- C. Amazon Transcribe
- D. Amazon Comprehend

**정답:** C

**해설:** Amazon Transcribe는 음성을 텍스트로 변환하는 사용 사례와 연결됩니다. 현재 기능과 지원 범위는 공식 서비스 문서에서 다시 확인해야 합니다. [D1 문서: AI 사용 사례와 기법 선택](../01-ai-ml-foundations/03-ai-use-cases-and-technique-selection.md)

### Q7 — 복수 응답

AI 기법이나 서비스를 선택할 때 확인해야 할 조건을 모두 고르세요.

- A. 원하는 출력 유형
- B. 데이터와 레이블의 품질
- C. 보안·규정 준수 요구
- D. 운영 비용과 지연 시간
- E. 모델이 클수록 항상 최선이라는 가정

**정답:** A, B, C, D

**해설:** 출력·데이터·보안·비용·성능 제약을 함께 봐야 합니다. 큰 모델이 항상 최선이라는 가정은 올바르지 않습니다. [D1 문서: AI 사용 사례와 기법 선택](../01-ai-ml-foundations/03-ai-use-cases-and-technique-selection.md)

### Q8 — 단일 선택

모델이 학습한 패턴을 이용해 새로운 주문에 반품 가능성을 계산합니다. 이 사용 시점은 무엇인가요?

- A. 훈련
- B. 추론
- C. 데이터 수집
- D. 레이블 지정

**정답:** B

**해설:** 학습된 모델이 새 입력에 결과를 내는 과정은 추론입니다. [D1 문서: AI·ML·GenAI의 관계](../01-ai-ml-foundations/01-ai-ml-genai-relationship.md)

### Q9 — 단일 선택

평가용 데이터를 훈련 과정에 사용하지 않고 별도로 보관하는 주된 이유는 무엇인가요?

- A. 모델이 평가 데이터를 정답처럼 외우지 않게 하려고
- B. 데이터 파일의 이름을 짧게 하려고
- C. 모든 모델을 생성형 AI로 바꾸려고
- D. 레이블을 항상 제거하려고

**정답:** A

**해설:** 별도의 평가 데이터는 새로운 입력에 대한 일반화 성능을 공정하게 확인하는 데 도움을 줍니다. [D1 문서: ML 개발 수명 주기와 MLOps](../01-ai-ml-foundations/04-ml-lifecycle-and-mlops.md)

### Q10 — 단일 선택

운영 중인 모델의 성능이 시간이 지나며 낮아지고 입력 데이터의 패턴도 변했습니다. 가장 먼저 연결할 ML 수명 주기 활동은 무엇인가요?

- A. 모니터링과 재훈련 검토
- B. 평가 단계 영구 삭제
- C. 레이블을 모두 제거
- D. 모델을 평가하지 않고 계속 배포

**정답:** A

**해설:** 운영 중 데이터와 성능 변화를 모니터링하고, 필요하면 데이터를 검토해 재훈련·재평가·재배포를 수행합니다. [D1 문서: ML 개발 수명 주기와 MLOps](../01-ai-ml-foundations/04-ml-lifecycle-and-mlops.md)

### Q11 — 복수 응답

MLOps의 목적과 관련 있는 설명을 모두 고르세요.

- A. 데이터와 모델 버전을 추적한다.
- B. 훈련·평가 과정을 반복 가능하게 한다.
- C. 운영 중인 모델을 모니터링한다.
- D. 업무 목표와 모델 지표를 연결한다.
- E. 모든 사람의 검토를 자동으로 없앤다.

**정답:** A, B, C, D

**해설:** MLOps는 반복·추적·모니터링과 지표 연결을 돕지만, 모든 사람의 검토를 제거하는 방법은 아닙니다. [D1 문서: ML 개발 수명 주기와 MLOps](../01-ai-ml-foundations/04-ml-lifecycle-and-mlops.md)

### Q12 — 단일 선택

모델 정확도는 좋아졌지만 실제 고객 처리 시간은 늘어났습니다. 무엇을 추가로 확인해야 하나요?

- A. 비즈니스 지표와 운영 지표
- B. 모델 이름의 길이
- C. 훈련 데이터의 파일 확장자만
- D. GenAI인지 여부만

**정답:** A

**해설:** 모델 지표가 좋아도 운영·비즈니스 결과가 좋아진다는 보장은 없습니다. 실제 업무 지표를 함께 확인해야 합니다. [D1 문서: ML 개발 수명 주기와 MLOps](../01-ai-ml-foundations/04-ml-lifecycle-and-mlops.md)

## 점수 해석

- 10~12개 정답: D1 핵심 개념을 D2의 GenAI 개념과 연결합니다.
- 7~9개 정답: 틀린 문제의 연결 문서를 다시 읽고 카드를 반복합니다.
- 0~6개 정답: D1 첫 문서부터 순서대로 다시 읽고 용어 퀴즈를 먼저 풉니다.
