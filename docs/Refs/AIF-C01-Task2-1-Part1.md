> 생성형 AI 기본 개념, 5개 강의 중 1번째

## 1. 생성형 AI란?

- **딥 러닝 하위 집합**, 다목적 기술
- 딥 러닝 기존 콘텐츠 찾거나 분류 대신 **독창적 새 콘텐츠 생성** 도움
- 텍스트 / 이미지 / 오디오 / 비디오 / 코드 같은 새 콘텐츠 생성 중점
- AI 사용자 예측 입력 데이터 기반 분류/예측 중점 기억 vs 생성형 AI 새 콘텐츠 생성
- 모델 대량 훈련 데이터 패턴/표현 학습 → 해당 지식 사용 훈련 데이터 유사 결과 생성
- 영역 1 설명: **방대한 양 데이터 훈련 파운데이션 모델 사용**, 자연어/이미지 같은 양식 통계적 패턴 찾음
- 파운데이션 모델 **수십억 파라미터 매우 크고 복잡한 신경망**, 파라미터 훈련 단계/사전 훈련 중 학습, 훈련 가능 파라미터 수↑→모델 크기↑→메모리↑→고급 태스크 수행 가능
- 그대로 사용 or **미세 조정 기법 적용 특정 사용 사례 맞춤**

## 2. 모델 구축 핵심

- 모델 생성형 AI 핵심, 다시 말해 **모델 = 신경망 + 시스템 리소스 + 데이터 + 프롬프트 모두 함께 작동 구축**
- 구축 시 학습 내용 기반 고유 결과물 생성 필요 지식 훈련
- 모델 사용자 입력 데이터/텍스트 받아 출력 제공, 출력 **다음 단어/토큰 무엇일지 추측**

## 3. 트랜스포머 네트워크

- 현재 핵심 요소 **트랜스포머 네트워크**, "Attention Is All You Need" 2017 논문 소개
- **ChatGPT 같은 일부 LLM 트랜스포머 아키텍처 기반 구축**
- LLM 인터넷 방대한 텍스트 데이터 기반 사전 훈련 → 광범위 지식 기반 구축 가능 + 비교적 적은 추가 데이터 특정 태스크 미세 조정 가능
- 생성형 AI 여러 콘텐츠 태스크/사용 사례 사용 가능
- 대규모 언어 모델 자연어/인간 작성 지시 받아 인간 수행처럼 태스크 수행 가능

## 4. 시험 필수 개념 용어

- **프롬프트 / 추론 / 완성(Completion) / 컨텍스트 창 / 토큰 / LLM 어휘 / 토크나이저 / 프롬프트 엔지니어링** 등 이해 필요

## 5. 계산 기반 - 통계/선형 대수

- 대부분 ML/AI/생성형 AI 모델 **확률 모델링 / 손실 함수 / 행렬 곱셈 포함 통계/선형 대수 계산 사용**
- ML 원시 텍스트/이미지/비디오 아닌 **숫자 사용 작업 선호** → 계산 딥 러닝 작업 사용

## 6. 프롬프트 엔지니어링 / 컨텍스트 내 학습

- 영역 1 프롬프트 사용 노래 생성 가사 프롬프트 포함, 첫 시도 원하는 결과 생성 못하는 상황 발생 → **프롬프트 엔지니어링 활용** 생성형 모델 이해 태스크/사용 사례 적용
- 더 나은 완성 생성 전략 중 하나 = 수행 원하는 태스크 예제 포함, 예제 프롬프트 내 통합
- **컨텍스트 창 내부 예제 제공 = 컨텍스트 내 학습 (In-Context Learning)**
- 예제/추가 데이터 프롬프트 포함 → LLM 요청 태스크 더 많이 학습 가능

### 프롬프트 정의

- 생성형 모델 전송 입력 = **프롬프트**
- 텍스트 프롬프트 LLM 및 이미지/비디오 등 기타 양식 사용
- 프롬프트 **추론 시간 동안 모델 전달 → 출력/완성 생성**
- **추론 구성 파라미터 프롬프트 완성 영향**
- 프롬프트 지침+콘텐츠 구성 but **퓨샷/제로샷/원샷 추론 사용 컨텍스트 내 학습 추가 가능**
