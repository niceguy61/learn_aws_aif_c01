## 1. ID 페더레이션 vs IAM 사용자 생성 관리

- 계정 IAM 사용자 생성 관리 대신 **ID 페더레이션 사용 권장**
- ID 페더레이션 = 사용자 **Active Directory 같은 자격 증명 제공업체 통해 인증**, 인증 마치면 AWS 임시 자격 증명 제공
- **AWS IAM Identity Center** 사용 외부 자격 증명 제공업체 통해 사용자 인증 또는 Identity Center에서 디렉터리 생성 이를 사용 인증 가능
- Identity Center에서는 사용자 **인력 사용자 / 인력 자격 증명**이라고 함
- 인증 완료 후 인력 사용자 **AWS 콘솔 액세스 선택 가능 포털 이동** 또는 권한 있는 모든 AWS 계정 임시 액세스 키 얻을 수 있음
- 여러 AWS 계정 사용 조직 큰 장점: 각 계정 IAM 사용자 관리 대신 사용자 AWS Identity Center 추가 + **하나 중앙 집중식 리포지토리 모든 계정 권한 관리**
- Identity Center 사용 사용자 그룹 배치 + 그룹 수준 권한 세트 할당 가능
- 역할 사용 임시 권한 부여 = 장기 자격 증명보다 더 나은 방법
- **AWS는 IAM 대신 IAM Identity Center 사용 사용자 관리 권장**

## 2. 보안 구성 감사/검증 - 로깅/검토

- 보안 구성 감사/검증 → 사용자 수행 작업 **로깅/검토** 가능해야 함

### AWS CloudTrail

- **CloudTrail = AWS 계정 의해 또는 계정 대신 수행 API 호출/관련 이벤트 캡처**
- 지정 S3 버킷 로그 파일 전달
- **SageMaker와 통합:** 엔드포인트 호출 제외 SageMaker 모든 API 호출 캡처
  - 예) 훈련 작업/노트북 인스턴스 생성 → 작업 추적 로깅
- CloudTrail 수집 정보 사용 SageMaker 요청 확인 가능, 요청 수행 IP 주소/요청 사용자/요청 시간/추가 세부 정보 확인 가능

## 3. 데이터 액세스 관리 - 공동 책임

- 공동 책임 모델 고객 데이터 액세스 관리해야 함 = 훈련 데이터/아티팩트 비공개 안전 유지

### S3 퍼블릭 액세스 차단 (Public Access Block)

- 모든 객체 퍼블릭 액세스 차단 사용 기능
- 현재/미래 액세스 **버킷 또는 계정 수준 차단 가능**
  - 버킷 수준 사용 시 계정 일부 버킷 공개 가능
  - 계정 수준 사용 시 기존/새 버킷 퍼블릭 액세스 권한 부여 불가
- 사용 시 버킷 정책/ACL 부여 모든 퍼블릭 권한 **재정의**

## 4. SageMaker Role Manager

- IAM 권한 정책 직접 생성 않고 ML 활동 수행 권한 부여 IAM 역할 생성 크게 간소화
- **12가지 ML 활동** 대한 **3가지 미리 구성된 역할 페르소나 + 미리 정의 권한** 제공
  - 다른 서비스 액세스 권한 포함: **S3/Glue/Athena/CloudWatch**
  - SageMaker 모델/엔드포인트/훈련 작업/파이프라인/실험 관리/모니터링 권한 제공
