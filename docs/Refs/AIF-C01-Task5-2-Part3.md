## 2. AWS Audit Manager

- **규정 준수 요구 AWS 사용 데이터 매핑**
- 규정 준수/미준수 증거 수집 + 감사자 제공 평가 보고서 생성
- 선택 프레임워크 기반 평가 생성, **프레임워크 = 감사 관련 제어 그룹화**
- **기본 제공 프레임워크:** 생성형 AI 모범 사례 / SOC 2 프레임워크 포함
- **자체 프레임워크 정의 가능:** 관심 특정 제어 평가 조정
- 평가 생성 시 프레임워크 정의 제어 따라 **AWS 계정/서비스 리소스 자동 평가**
- 관련 증거 수집 → 감사자 친숙 형식 변환 → 증거 평가 제어 첨부
- 감사 시점 수집 증거 검토 → 평가 보고서 추가, 제어가 의도대로 작동 입증 도움

## 3. Guardrails for Amazon Bedrock - 애플리케이션별 보호

- **사용 사례 + 책임감 있는 AI 정책 따라 애플리케이션별 보호 구현** Bedrock 기능

### 콘텐츠 필터

- **증오/모욕/성적/폭력 범주 유해 콘텐츠 필터링 가능 구성 가능한 임계값** 콘텐츠 필터 제공

### 주제 차단

- 간단한 자연어 설명 사용 애플리케이션 컨텍스트 내 차단 필요 **주제 정의** 가능
- 주제 인식 도움 몇 가지 예제 문구 선택 제공 가능
- **제한 주제 속 사용자 입력 + FM 응답 탐지/차단**

### PII 탐지

- 사용자 입력/FM 응답에서 **PII 탐지 가능**
- 사용 사례 따라 선택적으로 PII 포함 입력 거부 or FM 응답에서 PII 수정 (Redact)

### 임계값 구성

- 유해 상호 작용 필터링 위해 다양한 범주 임계값 구성 가능, 사용자 쿼리/FM 응답 자동 평가 제한 범주 콘텐츠 탐지/방지 도움
- 예) 전자 상거래 사이트 증오 발언/모욕 부적절 언어 사용 안하도록 온라인 어시스턴트 설계

### 특정 주제 차단 예시 + 메시지 2개

- 특정 주제 쉽게 차단 가능, 예) 투자 조언 제공 못하도록 차단→거부 주제 추가 간단 용어 설명 가능
- **응답 제공 2가지 메시지 지정 가능:** 하나는 프롬프트 차단 경우 / 다른 하나는 모델 응답 차단 경우
- 예) "죄송하지만 해당 주제는 저희 전문 분야를 벗어납니다."

## 4. AWS Config - 리소스 구성 변경 주의

- 목표 규정 준수 달성 but 잘못된 구성 같이 리소스 구성 변경 시 주의 필요

### Config

- **AWS 리소스 현재 구성 자세한 인벤토리 제공**
- 리소스 구성 변경 때마다 변경 사항 캡처 → 구성 기록 스냅샷 기록
- 변경 사항 **구성 규칙 따라 평가**, 규칙 준수 안하면 **Systems Manager Automation 문서 사용 자동 수정 가능**
- 사전 구축 규칙 사용 or Lambda 함수 사용 사용자 지정 규칙 생성 가능

### 적합성 팩 (Conformance Packs)

- 규정 준수 요구 충족 규칙/수정 배포 도움 일련 Config 규칙 + 수정 작업 함께 묶어 패키지 제공
- 직접 생성 or 템플릿 라이브러리 선택 가능
- **2가지 유용한 적합성 팩:** AI 및 ML 운영 모범 사례 / Amazon SageMaker 보안 모범 사례

## 5. Amazon Inspector - 애플리케이션 수준

- Config 리소스 수준 구성 모니터링 반면 **Inspector 애플리케이션 수준 작동**
- 애플리케이션/컨테이너에서 **EC2 인스턴스 개방형 액세스 / 취약 소프트웨어 버전 설치** 같은 보안 취약성 + 보안 모범 사례 편차 확인
- 자동 보안 평가 실행 → 보안/규정 준수 개선 가능
- 평가 수행 후 **보안 결과 목록 제공:** 각 문제 자세한 설명 + 해결 권장 사항 포함 **심각도 수준 따라 우선 순위 지정**

- **6범주 모범 사례 검사 사용 환경 지속 평가:** 비용 최적화 / 성능 / 복원력 / 보안 / 운영 우수성 / 서비스 한도
