# 데이터 유형과 지도·비지도·강화 학습

## 이 문서에서 배울 것

이 문서에서는 ML에 사용되는 데이터의 형태와 학습 방법을 구분합니다. 특히 **데이터에 정답 레이블이 있는가**, **모델이 어떤 방식으로 피드백을 받는가**를 기준으로 지도 학습·비지도 학습·강화 학습을 판단합니다.

## 선수 지식과 한 줄 요약

- 선수 지식: 표, 사진, 문장, 음성처럼 일상에서 다루는 데이터의 예를 알고 있으면 충분합니다.
- 한 줄 요약: **데이터 형태와 학습 방식은 서로 다른 분류이며, 레이블의 유무와 학습 피드백을 먼저 확인해야 합니다.**

## 핵심 개념을 쉬운 말로 설명

### 데이터 형태

| 데이터 형태 | 쉬운 설명 | 예시 |
|---|---|---|
| 정형 데이터 | 행과 열이 정해진 표 형태의 데이터 | 고객 나이, 구매 금액, 주문 날짜 |
| 반정형 데이터 | 일정한 태그나 키는 있지만 표 구조가 고정되지 않은 데이터 | JSON 문서, 애플리케이션 로그 |
| 비정형 데이터 | 미리 정해진 행·열 구조로 바로 정리하기 어려운 데이터 | 이미지, 자유 형식 문서, 음성, 영상 |
| 시계열 데이터 | 시간 순서가 중요한 데이터 | 시간별 판매량, 센서 측정값 |

데이터 형태는 “데이터가 어떻게 생겼는가”를 설명합니다. 이 분류만으로 어떤 학습 방법을 사용할지 결정할 수는 없습니다. 예를 들어 정형 데이터도 레이블이 있으면 지도 학습에 사용할 수 있고, 레이블이 없으면 비지도 학습에 사용할 수 있습니다.

### 레이블: 데이터에 붙은 정답 또는 목표 표시

레이블(label)은 학습 예시에 붙어 있는 정답 또는 예측 목표입니다. 이메일에 `스팸` 또는 `정상`이라는 표시가 붙어 있다면 이 표시가 레이블입니다.

레이블이 있으면 모델은 자신의 예측과 정답을 비교하면서 학습할 수 있습니다. 레이블을 만들려면 사람이 직접 분류하거나 기존 업무 시스템에서 정답을 가져와야 하므로 시간과 비용이 들 수 있습니다.

### 지도 학습: 정답을 보여 주며 학습

지도 학습(supervised learning)은 입력 데이터와 레이블을 함께 사용합니다. 선생님이 문제와 정답을 함께 보여 주는 상황에 비유할 수 있습니다.

- **분류(classification)**: 결과가 범주입니다. 예: 정상/스팸, 승인/거절.
- **회귀(regression)**: 결과가 연속적인 숫자입니다. 예: 다음 달 판매량, 주택 가격.

### 비지도 학습: 정답 없이 구조를 찾음

비지도 학습(unsupervised learning)은 레이블이 없는 데이터에서 반복되는 구조나 비슷한 그룹을 찾습니다. 여러 물건을 종류별 상자에 넣되, 처음부터 상자 이름을 알려 주지 않는 상황에 비유할 수 있습니다.

- **클러스터링(clustering)**: 서로 비슷한 데이터를 그룹으로 묶습니다.
- 데이터 그룹의 이름이나 의미는 분석가가 결과를 살펴보고 해석할 수 있습니다.

비지도 학습은 정답 레이블이 없다는 뜻이지, 데이터가 없다는 뜻이 아닙니다.

### 강화 학습: 행동의 결과로부터 학습

강화 학습(reinforcement learning)은 에이전트가 환경에서 행동을 선택하고, 그 결과로 보상 또는 불이익을 받으며 더 나은 행동을 찾는 방식입니다. 게임을 여러 번 하면서 점수를 높이는 방법을 배우는 상황에 비유할 수 있습니다.

강화 학습의 핵심은 각 입력에 정답 레이블을 붙이는 것이 아니라, 행동의 결과를 나타내는 피드백을 사용한다는 점입니다.

## 학습 방식 비교

| 구분 | 지도 학습 | 비지도 학습 | 강화 학습 |
|---|---|---|---|
| 학습 자료 | 입력과 레이블 | 레이블 없는 입력 | 상태·행동·보상 |
| 목표 | 정답에 가까운 예측 | 숨은 구조나 그룹 발견 | 장기 보상 최대화 |
| 대표 작업 | 분류, 회귀 | 클러스터링 | 순차적인 행동 선택 |
| 질문 형태 | “이 입력의 정답은 무엇인가?” | “비슷한 데이터끼리 어떻게 묶이는가?” | “어떤 행동이 결과적으로 가장 좋은가?” |

## AWS 관점과 관련 서비스

AWS에서 ML 모델의 데이터를 준비하고 학습·평가·배포하는 전체 흐름을 고려할 때 Amazon SageMaker AI를 연결할 수 있습니다. 실제 설계에서는 데이터 저장 위치, 레이블 품질, 접근 권한, 비용과 운영 부담을 함께 검토합니다. [AWS 공식 Domain 1](https://docs.aws.amazon.com/ko_kr/aws-certification/latest/ai-practitioner-01/ai-practitioner-01-domain1.html)

AWS 서비스 이름을 고르는 문제에서도 먼저 학습 방식과 결과 유형을 정한 뒤, 관리형 서비스가 필요한지 또는 직접 모델 개발이 필요한지 판단합니다. 특정 서비스 기능과 현재 제공 범위는 공식 서비스 문서로 다시 확인해야 합니다.

## 비슷한 개념·서비스 비교

### 데이터 형태와 학습 방식은 같은 분류가 아닙니다

- 정형·반정형·비정형은 데이터의 **모양**을 설명합니다.
- 지도·비지도·강화 학습은 모델이 **배우는 방식**을 설명합니다.
- 따라서 “비정형 데이터니까 비지도 학습”처럼 바로 연결하면 안 됩니다.

### 분류와 회귀는 모두 지도 학습입니다

분류는 정해진 범주를 고르고, 회귀는 숫자 값을 예측합니다. “고객이 이탈하는가?”는 분류에 가깝고, “다음 달 이탈 가능성이 몇 퍼센트인가?”는 문제의 출력 정의에 따라 확률 예측으로 표현될 수 있습니다. 문제에서는 선택지와 출력 형식을 함께 확인해야 합니다.

## 실무형 시나리오

온라인 쇼핑몰이 세 가지 분석을 하려고 합니다.

1. 과거 주문에 `반품` 또는 `반품 아님` 표시가 있고 새 주문의 반품 여부를 예측하려면 지도 학습의 분류 문제입니다.
2. 고객의 구매 기록에 정답 표시가 없지만 비슷한 구매 패턴의 고객 그룹을 찾으려면 비지도 학습의 클러스터링 문제입니다.
3. 추천 시스템이 여러 상품을 보여 주고 장기적인 구매·만족 피드백을 바탕으로 추천 순서를 바꾸려면 강화 학습을 고려할 수 있습니다.

세 경우 모두 데이터가 필요하지만, 레이블과 피드백의 형태가 다릅니다.

## 시험에서 판단하는 단서

- “정답 레이블이 제공된다” → 지도 학습
- “레이블 없이 비슷한 그룹을 찾는다” → 비지도 학습, 특히 클러스터링
- “행동, 환경, 보상, 장기적인 보상” → 강화 학습
- “예측 결과가 범주” → 분류
- “예측 결과가 숫자” → 회귀
- “데이터가 표인지 이미지인지”와 “학습 방식이 무엇인지”를 별도 질문으로 나눕니다.

## 자주 하는 오해

### 오해 1: 레이블이 없으면 ML을 할 수 없다

레이블이 없는 데이터에서도 비지도 학습으로 그룹이나 구조를 찾을 수 있습니다. 다만 지도 학습처럼 명시적인 정답과 비교하는 방식은 아닙니다.

### 오해 2: 정형 데이터는 항상 지도 학습이다

정형 데이터라도 레이블이 없으면 비지도 학습에 사용할 수 있습니다. 데이터 형태와 레이블 유무는 별도로 확인해야 합니다.

### 오해 3: 강화 학습은 정답을 한 번에 알려 주는 학습이다

강화 학습은 행동의 결과에 따른 보상 또는 불이익을 사용합니다. 각 상황에 정답 레이블을 미리 붙이는 지도 학습과 구분합니다.

### 오해 4: 클러스터의 이름은 모델이 업무 의미까지 자동으로 정해 준다

클러스터링은 비슷한 데이터 그룹을 찾는 데 도움을 주지만, 각 그룹이 사업적으로 무엇을 의미하는지는 사람이 결과를 해석해야 할 수 있습니다.

## 핵심 정리

- 정형·반정형·비정형·시계열은 데이터의 형태를 설명합니다.
- 지도 학습은 레이블이 있는 예시로 예측합니다.
- 비지도 학습은 레이블 없이 구조나 그룹을 찾습니다.
- 강화 학습은 행동의 결과인 보상 피드백으로 학습합니다.
- 분류는 범주, 회귀는 숫자, 클러스터링은 비슷한 그룹을 다룹니다.

**한 문장 암기 포인트:** `레이블이 있으면 지도`, `레이블 없이 그룹을 찾으면 비지도`, `행동 결과의 보상을 배우면 강화`입니다.

## 스스로 답하는 확인 질문

1. 고객 데이터에 이미 `구매함/구매하지 않음` 레이블이 있다면 어떤 학습 방식을 먼저 고려하나요?
2. 레이블이 없는 고객을 구매 패턴별로 묶는다면 어떤 작업인가요?
3. “다음 달 판매량”과 “판매량이 높음/낮음”은 회귀와 분류 중 각각 어디에 가까운가요?
4. 에이전트가 행동을 선택하고 보상을 받는다는 단서가 왜 강화 학습을 가리키나요?
