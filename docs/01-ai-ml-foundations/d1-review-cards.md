# D1 복습 카드

## 사용 방법

앞면의 질문에 먼저 답한 뒤 뒷면을 확인합니다. 답을 외우는 것보다 왜 그런지 한 문장으로 설명하는 것이 중요합니다. 이 카드는 [AI·ML·GenAI의 관계](01-ai-ml-genai-relationship.md), [데이터 유형과 학습 유형](02-data-and-learning-types.md), [AI 사용 사례와 기법 선택](03-ai-use-cases-and-technique-selection.md), [ML 개발 수명 주기와 MLOps](04-ml-lifecycle-and-mlops.md)를 짧게 반복하기 위한 자료입니다.

## 핵심 카드

| 앞면 | 뒷면 |
|---|---|
| AI와 ML의 관계는? | AI는 넓은 목표이고 ML은 데이터를 통해 패턴을 학습하는 대표적인 AI 접근 방식입니다. |
| 딥 러닝은 무엇인가요? | 여러 층의 신경망을 사용하는 ML 접근 방식입니다. |
| GenAI는 어떤 결과를 만드나요? | 텍스트·이미지·오디오·비디오 같은 새로운 콘텐츠를 생성합니다. |
| 훈련과 추론의 차이는? | 훈련은 모델이 패턴을 배우는 과정이고 추론은 학습된 모델이 새 입력에 결과를 내는 과정입니다. |
| 레이블이란? | 학습 예시에 붙은 정답 또는 예측 목표입니다. |
| 지도 학습의 핵심 단서는? | 입력과 정답 레이블이 함께 제공됩니다. |
| 비지도 학습의 핵심 단서는? | 레이블 없이 데이터의 구조나 비슷한 그룹을 찾습니다. |
| 강화 학습의 핵심 단서는? | 에이전트가 행동을 선택하고 그 결과의 보상 또는 불이익을 받습니다. |
| 분류와 회귀의 차이는? | 분류는 범주를 예측하고 회귀는 숫자 값을 예측합니다. |
| 클러스터링이란? | 레이블 없이 비슷한 데이터를 그룹으로 묶는 작업입니다. |
| 데이터 형태와 학습 방식은 같은 분류인가요? | 아닙니다. 정형·반정형·비정형은 데이터 모양이고 지도·비지도·강화는 학습 방식입니다. |
| AI 문제를 풀 때 첫 단계는? | 업무 목표와 원하는 결과를 한 문장으로 구체화합니다. |
| 이미지 속 결함을 찾는 문제는? | 컴퓨터 비전 문제로 연결합니다. |
| 음성을 글자로 바꾸는 문제는? | 음성 인식 문제로 연결합니다. |
| 텍스트로 새 답변 초안을 만드는 문제는? | 생성형 AI 사용 사례로 연결하되 결과 검증과 사람 검토를 고려합니다. |
| ML 수명 주기의 시작은? | 비즈니스 문제와 모델이 제공할 결과를 정의하는 것입니다. |
| 평가 데이터를 따로 두는 이유는? | 모델이 새로운 입력에 일반화되는지 공정하게 확인하기 위해서입니다. |
| 배포 후에도 필요한 활동은? | 운영 모니터링, 성능·데이터 변화 확인, 필요 시 재훈련입니다. |
| MLOps의 목적은? | 데이터와 모델의 개발·배포·운영을 반복 가능하고 추적 가능하게 만드는 것입니다. |
| 모델 지표와 비즈니스 지표를 함께 보는 이유는? | 모델 성능이 좋아도 실제 업무 목표가 개선되지 않을 수 있기 때문입니다. |

## 한 장 요약

```text
AI
└─ ML
   └─ 딥 러닝
      └─ 일부 GenAI

레이블 있음 → 지도 학습
레이블 없음 + 그룹 찾기 → 비지도 학습
행동 + 보상 → 강화 학습

범주 → 분류 | 숫자 → 회귀 | 비슷한 그룹 → 클러스터링

문제 정의 → 데이터 → 훈련 → 평가 → 배포 → 모니터링 → 개선
```
