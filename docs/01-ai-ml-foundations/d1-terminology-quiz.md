# D1 용어 퀴즈

## 풀기 전에

각 문항을 먼저 풀고 아래 정답과 해설을 확인합니다. 이 퀴즈는 공식 시험 문항이 아니며, D1 개념을 확인하기 위한 자체 제작 학습 자료입니다.

## 문제

1. 다음 중 가장 넓은 상위 개념은 무엇인가요?
   - A. AI
   - B. ML
   - C. 딥 러닝
   - D. 클러스터링

2. 학습 예시와 정답 레이블을 함께 사용하는 방식은 무엇인가요?
   - A. 지도 학습
   - B. 비지도 학습
   - C. 강화 학습
   - D. 규칙 기반 처리

3. 레이블 없이 비슷한 고객을 그룹으로 묶는 작업은 무엇인가요?
   - A. 회귀
   - B. 분류
   - C. 클러스터링
   - D. 음성 합성

4. 강화 학습을 나타내는 단서는 무엇인가요?
   - A. 정답 레이블이 있는 이미지
   - B. 행동의 결과로 받는 보상
   - C. 행과 열로 정리된 표
   - D. 미리 정해진 범주

5. 다음 중 회귀 문제에 가장 가까운 것은 무엇인가요?
   - A. 거래가 사기인지 정상인지 판단
   - B. 다음 달 판매량 예측
   - C. 고객을 행동별 그룹으로 묶기
   - D. 음성을 텍스트로 변환

6. 훈련(training)에 대한 설명으로 맞는 것은 무엇인가요?
   - A. 새 입력에 결과를 내는 운영 단계
   - B. 모델이 데이터의 패턴을 배우는 단계
   - C. 사용자의 권한을 설정하는 단계
   - D. 결과를 사람이 검토하는 단계

7. 다음 중 비정형 데이터의 예는 무엇인가요?
   - A. 고정된 열의 고객 테이블
   - B. 이미지 파일
   - C. 월별 매출 표
   - D. 정해진 범주의 코드 목록

8. 이미지에서 제품 결함을 찾는 사용 사례는 어떤 AI 분야와 연결되나요?
   - A. 컴퓨터 비전
   - B. 회귀만 가능
   - C. 음성 합성
   - D. 데이터베이스 백업

9. 음성을 텍스트로 바꾸는 작업에 연결되는 AWS 서비스는 무엇인가요?
   - A. Amazon Transcribe
   - B. Amazon Polly
   - C. Amazon Translate
   - D. Amazon Lex

10. ML 수명 주기에서 모델을 실제 애플리케이션이 사용할 수 있게 하는 단계는 무엇인가요?
    - A. 배포
    - B. 레이블 지정
    - C. 클러스터링
    - D. 문제 정의 이전

11. 다음 중 MLOps의 목적에 해당하는 것을 모두 고르세요.
    - A. 데이터와 모델 버전을 추적한다.
    - B. 운영 중인 모델을 모니터링한다.
    - C. 모든 문제에서 사람의 판단을 제거한다.
    - D. 재훈련과 배포 절차를 반복 가능하게 한다.

12. 다음 중 AI 기법이나 서비스 선택 시 고려할 조건을 모두 고르세요.
    - A. 원하는 출력 유형
    - B. 데이터와 레이블의 품질
    - C. 보안·규정 준수 요구
    - D. 모델이 클수록 항상 정답이라는 가정

## 정답과 해설

1. **A** — AI가 가장 넓은 개념이고 ML·딥 러닝은 그 안에 포함될 수 있는 접근 방식입니다.
2. **A** — 지도 학습은 입력과 레이블을 함께 사용합니다.
3. **C** — 레이블 없이 비슷한 데이터를 묶는 작업은 클러스터링입니다.
4. **B** — 행동과 그 결과의 보상은 강화 학습의 핵심 단서입니다.
5. **B** — 판매량처럼 연속적인 숫자 값을 예측하는 문제는 회귀에 가깝습니다.
6. **B** — 훈련은 모델이 데이터에서 패턴을 학습하는 단계입니다.
7. **B** — 이미지는 고정된 행·열 구조로 바로 표현하기 어려운 비정형 데이터의 예입니다.
8. **A** — 이미지 속 대상이나 결함을 다루는 문제는 컴퓨터 비전과 연결됩니다.
9. **A** — Amazon Transcribe는 음성을 텍스트로 변환하는 사용 사례와 연결됩니다.
10. **A** — 배포는 평가한 모델을 실제 사용 환경에 제공하는 단계입니다.
11. **A, B, D** — MLOps는 추적·모니터링·반복 가능한 절차를 돕지만 사람의 판단을 항상 제거하지는 않습니다.
12. **A, B, C** — 출력, 데이터 품질, 보안과 규정 준수는 중요한 선택 조건입니다. 큰 모델이 항상 최선이라는 가정은 올바르지 않습니다.
