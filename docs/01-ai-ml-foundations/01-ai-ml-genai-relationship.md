# AI, ML, 딥 러닝, GenAI의 관계

## 이 문서에서 배울 것

이 문서에서는 AI(Artificial Intelligence), ML(Machine Learning), 딥 러닝(Deep Learning), GenAI(Generative AI)를 큰 범주와 작은 범주의 관계로 구분합니다. 시험 문제에서 네 용어가 함께 등장해도 각각의 역할을 빠르게 파악하는 것이 목표입니다.

## 선수 지식과 한 줄 요약

- 선수 지식: 컴퓨터가 사람이 하던 판단이나 생성 작업을 도울 수 있다는 정도만 알고 있으면 됩니다.
- 한 줄 요약: **AI는 가장 넓은 개념이고, ML은 데이터에서 학습하는 방법이며, 딥 러닝은 신경망 기반 ML이고, GenAI는 새로운 콘텐츠를 생성하는 AI입니다.**

## 핵심 개념을 쉬운 말로 설명

### AI: 가장 넓은 목표

인공지능(AI)은 컴퓨터 시스템이 사람이 지능을 사용한다고 느끼는 작업을 수행하도록 만드는 넓은 분야입니다. 예를 들면 음성을 글자로 바꾸거나, 문장을 번역하거나, 이미지 속 대상을 구분하거나, 질문에 답하는 작업이 있습니다.

AI라는 말만으로는 시스템이 어떤 방법으로 결과를 냈는지 알 수 없습니다. 사람이 직접 만든 규칙을 사용할 수도 있고, 데이터에서 패턴을 학습하는 ML을 사용할 수도 있습니다.

### ML: 데이터에서 패턴을 학습하는 방법

머신 러닝(ML)은 모든 판단 규칙을 사람이 하나씩 작성하는 대신, 예시 데이터에서 패턴을 찾아 새로운 입력에 대한 결과를 예측하는 방법입니다.

예를 들어 이메일 수천 개와 스팸 여부를 보여주면, ML 모델은 스팸과 관련된 패턴을 학습할 수 있습니다. 학습이 끝난 뒤 새 이메일이 들어오면 스팸일 가능성을 계산하는데, 이 사용 시점이 추론입니다.

### 딥 러닝: 신경망을 사용하는 ML

딥 러닝은 여러 층의 신경망을 사용하는 ML 접근 방식입니다. 이미지·음성·텍스트처럼 패턴이 복잡한 데이터에서 강력한 표현을 학습하는 데 사용될 수 있습니다.

여기서 “깊다”는 말은 사람이 이해하기 어려운 깊은 생각을 한다는 뜻이 아니라, 모델 안에 여러 계산 층이 있다는 뜻입니다.

### GenAI: 새로운 콘텐츠를 생성하는 AI

생성형 AI(GenAI)는 학습한 패턴을 바탕으로 텍스트·이미지·오디오·비디오 같은 새로운 콘텐츠를 만들어 내는 AI입니다.

기존의 분류 모델이 “이 이메일은 스팸인가?”처럼 정해진 범주를 고르는 데 집중한다면, GenAI는 “고객에게 보낼 답변 초안을 작성해 줘”처럼 새로운 결과를 만들어 낼 수 있습니다. GenAI도 ML과 딥 러닝을 활용할 수 있지만, 모든 ML이 GenAI인 것은 아닙니다.

## 포함 관계로 보기

```text
AI
├─ 규칙 기반 시스템
└─ ML
   ├─ 전통적인 ML 방법
   └─ 딥 러닝
      └─ 일부 생성형 AI 시스템
```

이 그림은 모든 서비스와 모델의 세부 구조를 표현한 것이 아니라, 시험에서 사용할 기본적인 개념 관계를 보여주는 학습용 그림입니다.

## AWS 관점과 관련 서비스

AWS에서는 직접 모델을 개발하는 방법뿐 아니라, 특정 AI 작업을 API 형태로 이용하거나 모델 개발을 관리형 서비스로 수행하는 방법도 제공합니다. D1에서는 서비스 이름을 외우기보다 **문제 유형과 관리 수준을 연결하는 것**이 중요합니다.

| 필요한 작업 | 연결해 볼 AWS 서비스 | 초보자 관점 |
|---|---|---|
| ML 모델을 만들고 학습·배포하는 전체 흐름 | Amazon SageMaker AI | 모델 개발 수명 주기를 관리하는 서비스로 연결합니다. |
| 음성을 텍스트로 변환 | Amazon Transcribe | 음성 입력을 텍스트로 바꾸는 작업과 연결합니다. |
| 언어를 다른 언어로 변환 | Amazon Translate | 번역 작업과 연결합니다. |
| 텍스트에서 의미나 감정을 분석 | Amazon Comprehend | 텍스트 분석 작업과 연결합니다. |
| 대화형 봇의 입력과 대화 흐름 처리 | Amazon Lex | 대화형 애플리케이션과 연결합니다. |
| 텍스트를 음성으로 변환 | Amazon Polly | 음성 출력 작업과 연결합니다. |

위 표는 D1 학습을 위한 사용 사례 연결입니다. 각 서비스의 현재 기능, 지원 언어, 리전, 요금은 시험 범위와 별도로 해당 서비스의 공식 문서에서 확인해야 합니다. [AWS 공식 Domain 1](https://docs.aws.amazon.com/ko_kr/aws-certification/latest/ai-practitioner-01/ai-practitioner-01-domain1.html)

## 비슷한 개념 비교

| 개념 | 핵심 질문 | 대표 결과 | 흔한 오해 |
|---|---|---|---|
| AI | 컴퓨터가 어떤 지능적인 작업을 수행하게 할 것인가? | 예측, 인식, 대화, 생성 등 | AI는 항상 ML을 사용한다고 생각함 |
| ML | 데이터에서 패턴을 학습해 새 입력에 적용할 것인가? | 분류, 예측, 추천 | 학습이 끝나면 추가 입력이 필요 없다고 생각함 |
| 딥 러닝 | 신경망의 여러 층으로 복잡한 패턴을 학습할 것인가? | 이미지·음성·텍스트 처리 등 | 딥 러닝과 모든 ML을 같은 뜻으로 사용함 |
| GenAI | 새로운 콘텐츠를 생성할 것인가? | 텍스트, 이미지, 오디오 등 | 생성 결과가 항상 사실이라고 생각함 |

## 실무형 시나리오

한 회사가 고객 문의 이메일을 자동으로 처리하려고 합니다.

1. 이메일이 스팸인지 구분하려면 분류 문제로 볼 수 있습니다.
2. 이메일 내용을 다른 언어로 바꾸려면 번역 기능이 필요합니다.
3. 문의에 대한 새로운 답변 초안을 만들려면 GenAI를 고려할 수 있습니다.
4. 어떤 접근 방식을 선택하든 정확성, 사람 검토, 데이터 보호, 비용을 함께 검토해야 합니다.

핵심은 “AI를 사용한다”에서 멈추지 않고, **결과가 분류인지, 변환인지, 생성인지**를 먼저 구분하는 것입니다.

## 시험에서 판단하는 단서

- “데이터에서 패턴을 학습”하면 ML을 우선 떠올립니다.
- “여러 층의 신경망” 또는 복잡한 이미지·음성·텍스트 패턴이면 딥 러닝을 떠올립니다.
- “새로운 텍스트·이미지·오디오를 생성”하면 GenAI를 떠올립니다.
- “AI”만 제시되고 학습 방식이 제시되지 않으면 가장 넓은 상위 개념일 수 있습니다.
- 서비스 선택 문제에서는 먼저 결과가 **분류·예측·변환·생성** 중 무엇인지 확인합니다.

## 자주 하는 오해

### 오해 1: AI와 ML은 완전히 같은 말이다

ML은 AI를 구현하는 여러 방법 중 하나입니다. 규칙 기반 시스템처럼 ML이 아닌 AI 접근 방식도 있을 수 있으므로, 두 용어를 항상 동의어로 취급하지 않습니다.

### 오해 2: 딥 러닝은 ML과 별개의 기술이다

딥 러닝은 ML의 한 종류입니다. “ML보다 더 발전한 별도 분야”라고 외우기보다, 신경망을 사용하는 ML 접근 방식이라고 이해합니다.

### 오해 3: GenAI의 모든 출력은 정답이다

GenAI는 그럴듯한 결과를 만들 수 있지만, 결과가 사실인지 자동으로 보장하지는 않습니다. 실제 애플리케이션에서는 검증과 사람 검토가 필요할 수 있습니다.

### 오해 4: 모델이 학습되면 추론은 필요 없다

훈련은 모델이 패턴을 배우는 과정이고, 추론은 학습된 모델이 새 입력에 결과를 내는 과정입니다. 둘은 목적과 시점이 다릅니다.

## 핵심 정리

- AI는 가장 넓은 상위 개념입니다.
- ML은 데이터에서 패턴을 학습하는 AI 접근 방식입니다.
- 딥 러닝은 여러 층의 신경망을 사용하는 ML입니다.
- GenAI는 새로운 콘텐츠를 생성하는 AI입니다.
- 문제를 보면 먼저 분류·예측·변환·생성 중 어떤 결과를 원하는지 확인합니다.

**한 문장 암기 포인트:** `AI`는 큰 목표, `ML`은 데이터 학습, `딥 러닝`은 신경망 기반 ML, `GenAI`는 새로운 콘텐츠 생성입니다.

## 스스로 답하는 확인 질문

1. 데이터에서 패턴을 학습해 새 고객 문의가 긴급한지 판단한다면 AI·ML·GenAI 중 어떤 개념을 우선 연결해야 하나요? 왜 그런가요?
2. 여러 층의 신경망을 사용해 이미지에서 객체를 찾는다면 어떤 개념이 ML과 어떤 관계에 있나요?
3. 고객 문의에 새로운 답변 초안을 만들어 내는 작업이 단순 분류와 다른 이유는 무엇인가요?
4. 음성을 글자로 바꾸는 문제와 텍스트로 새로운 답변을 만드는 문제는 결과 유형이 어떻게 다른가요?
