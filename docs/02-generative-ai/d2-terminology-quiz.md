# D2 용어 퀴즈

## 풀기 전에

각 문항을 먼저 풀고 정답과 해설을 확인합니다. 이 퀴즈는 공식 시험 문항이 아니며, AIF-C01 D2 개념을 확인하기 위한 자체 제작 학습 자료입니다.

## 문제

1. 모델이 입력과 출력을 나누어 처리하는 단위는 무엇인가요?
   - A. 토큰
   - B. 리전
   - C. 엔드포인트
   - D. 레이블

2. 긴 문서를 검색에 적합한 작은 조각으로 나누는 작업은 무엇인가요?
   - A. 청킹
   - B. 추론
   - C. 배포
   - D. 중복성

3. 텍스트를 의미를 반영한 숫자 표현으로 바꾸는 것은 무엇인가요?
   - A. 임베딩
   - B. 오케스트레이션
   - C. 환각
   - D. 미세 조정

4. 질문과 관련된 외부 문서를 검색해 모델 입력에 제공하는 접근은 무엇인가요?
   - A. RAG
   - B. 분류
   - C. 회귀
   - D. 데이터 레지던시

5. 모델에게 작업·맥락·제약·출력 형식을 전달하는 입력은 무엇인가요?
   - A. 프롬프트
   - B. 벡터 인덱스
   - C. 리전
   - D. 처리량

6. 여러 데이터 형식을 입력 또는 출력으로 다루는 모델은 무엇인가요?
   - A. 멀티모달 모델
   - B. 회귀 모델
   - C. 단일 리전 모델
   - D. 배치 모델만

7. 다음 중 환각의 설명으로 가장 알맞은 것은 무엇인가요?
   - A. 모델이 입력을 토큰으로 나누는 현상
   - B. 모델이 사실이 아닌 내용을 그럴듯하게 생성하는 현상
   - C. 모델이 항상 같은 답을 내는 현상
   - D. 모델이 데이터를 암호화하는 현상

8. 같은 질문에 결과가 달라질 수 있는 특성은 무엇인가요?
   - A. 비결정성
   - B. 청킹
   - C. 임베딩
   - D. 레이블링

9. 다음 중 모델 선택 조건에 해당하는 것을 모두 고르세요.
   - A. 작업과 모달리티
   - B. 품질·비용·지연 시간
   - C. 보안·규정 준수
   - D. 모델이 클수록 항상 최선이라는 가정

10. 잘못된 답변의 영향이 큰 업무에서 모델 출력 전에 둘 수 있는 통제는 무엇인가요?
    - A. 사람 검토
    - B. 토큰 삭제
    - C. 리전 이름 변경
    - D. 모델 평가 생략

11. 여러 FM을 선택·호출해 GenAI 애플리케이션을 구성하는 관리형 AWS 서비스는 무엇인가요?
    - A. Amazon Bedrock
    - B. Amazon Q
    - C. Amazon Polly
    - D. Amazon Route 53

12. 모델 훈련·사용자 지정·배포 등 ML 개발 수명 주기를 폭넓게 다루는 AWS 플랫폼은 무엇인가요?
    - A. Amazon SageMaker AI
    - B. Amazon Q
    - C. Amazon Bedrock AgentCore만
    - D. Amazon S3 Glacier

13. 조직의 업무 데이터와 개발 작업을 돕는 생성형 AI 어시스턴트는 무엇인가요?
    - A. Amazon Q
    - B. SageMaker JumpStart
    - C. Strands Agents
    - D. 벡터

14. 다음 중 Strands Agents와 Amazon Bedrock AgentCore의 구분으로 맞는 것은 무엇인가요?
    - A. Strands Agents는 에이전트 개발 SDK이고 AgentCore는 에이전트 운영 기반이다.
    - B. 둘 다 데이터베이스 저장소다.
    - C. Strands Agents는 가격표이고 AgentCore는 토큰 단위다.
    - D. Strands Agents는 리전이고 AgentCore는 레이블이다.

15. 트래픽이 예측 가능하고 처리량과 지연 시간을 일정하게 계획하려고 할 때 온디맨드와 비교할 수 있는 것은 무엇인가요?
    - A. Provisioned Throughput
    - B. 환각
    - C. 청킹
    - D. 확산 모델

## 정답과 해설

1. **A** — 토큰은 모델이 입력과 출력을 처리하는 단위입니다.
2. **A** — 청킹은 긴 자료를 처리·검색에 적합한 조각으로 나누는 작업입니다.
3. **A** — 임베딩은 데이터를 의미를 반영한 숫자 벡터로 표현합니다.
4. **A** — RAG는 외부 자료를 검색해 모델의 컨텍스트로 제공하는 접근입니다.
5. **A** — 프롬프트는 모델에 작업 지시와 맥락·제약을 전달합니다.
6. **A** — 멀티모달 모델은 텍스트·이미지·오디오·비디오 등 여러 형식을 다룹니다.
7. **B** — 환각은 사실이 아닌 내용이 그럴듯하게 생성되는 현상입니다.
8. **A** — 비결정성 때문에 같은 질문도 설정과 컨텍스트 등에 따라 결과가 달라질 수 있습니다.
9. **A, B, C** — 작업·모달리티·품질·비용·지연 시간·보안·규정 준수를 함께 봅니다. 큰 모델이 항상 최선은 아닙니다.
10. **A** — 고위험 업무에서는 사람 검토와 최종 승인을 통제 장치로 설계할 수 있습니다.
11. **A** — Amazon Bedrock은 여러 FM을 활용하는 관리형 GenAI 애플리케이션 플랫폼입니다.
12. **A** — Amazon SageMaker AI는 모델 개발·훈련·사용자 지정·배포를 폭넓게 다룹니다.
13. **A** — Amazon Q는 조직·개발자 업무를 돕는 생성형 AI 어시스턴트입니다.
14. **A** — Strands Agents는 개발 SDK이고 AgentCore는 에이전트 운영·연결·보호를 위한 기반입니다.
15. **A** — Provisioned Throughput은 예측 가능한 처리량이 중요한 경우 온디맨드와 비교합니다.

## 복습 기준

- 13~15개 정답: D2 문제은행으로 시나리오 판단을 연습합니다.
- 10~12개 정답: 틀린 문항의 연결 문서를 다시 읽고 복습 카드를 반복합니다.
- 9개 이하 정답: [GenAI 핵심 개념](01-genai-core-concepts.md)부터 순서대로 다시 읽습니다.
