# D2 복습 카드

## 사용 방법

앞면의 질문에 먼저 답한 뒤 뒷면을 확인합니다. 정의를 외우는 데서 멈추지 말고 “이 단서가 나오면 어떤 선택을 하는가?”까지 한 문장으로 설명해 보세요. 이 카드는 [GenAI 핵심 개념](01-genai-core-concepts.md), [GenAI의 기능·한계와 비즈니스 문제](02-genai-capabilities-and-limitations.md), [AWS GenAI 인프라·기술과 비용](03-aws-genai-infrastructure-and-cost.md)를 반복하기 위한 자료입니다.

## 핵심 카드

| 앞면 | 뒷면 |
|---|---|
| 토큰이란? | 모델이 입력과 출력을 처리하기 위해 나누어 다루는 텍스트 등의 단위입니다. |
| 토큰 수가 비용과 어떤 관계가 있나요? | 모델과 가격 방식에 따라 입력·출력 토큰 양이 호출 비용에 영향을 줍니다. |
| 청킹이란? | 긴 문서나 데이터를 검색·처리에 적합한 작은 조각으로 나누는 것입니다. |
| 임베딩이란? | 텍스트나 다른 데이터를 의미를 반영한 숫자 벡터로 표현하는 것입니다. |
| 벡터 검색의 목적은? | 질문 벡터와 의미가 가까운 자료 벡터를 찾아 관련 컨텍스트를 제공하는 것입니다. |
| 프롬프트란? | 모델에게 작업·맥락·제약·출력 형식을 전달하는 입력입니다. |
| 컨텍스트 엔지니어링이란? | 모델이 작업에 필요한 지식과 지시를 사용하도록 입력 컨텍스트 전체를 설계하는 것입니다. |
| Transformer의 핵심 역할은? | 입력 토큰 사이의 관계를 주의 메커니즘 등으로 처리해 언어·콘텐츠 패턴을 학습하고 생성하는 데 사용됩니다. |
| LLM이란? | 대규모 텍스트 데이터로 학습해 언어 이해와 생성을 수행하는 대규모 언어 모델입니다. |
| 파운데이션 모델(FM)이란? | 여러 작업의 기반으로 사용할 수 있도록 넓은 데이터로 사전 훈련된 모델입니다. |
| LLM과 FM의 관계는? | LLM은 언어에 초점을 둔 FM의 한 종류로 볼 수 있으며, 모든 FM이 LLM인 것은 아닙니다. |
| 멀티모달 모델이란? | 텍스트·이미지·오디오·비디오처럼 둘 이상의 데이터 형식을 입력 또는 출력으로 다루는 모델입니다. |
| 확산 모델은 무엇에 자주 사용되나요? | 노이즈를 점진적으로 제거하는 방식으로 이미지 같은 콘텐츠를 생성하는 데 사용됩니다. |
| GenAI와 전통적 예측 모델의 차이는? | GenAI는 새로운 콘텐츠를 만들고, 전통적 예측 모델은 분류·수치 예측 같은 결과를 내는 데 초점을 둡니다. |
| 에이전트란? | 목표를 달성하기 위해 모델의 추론과 도구·외부 시스템 호출을 여러 단계로 조합하는 애플리케이션입니다. |
| 도구(tool)의 역할은? | 모델이 데이터 조회나 API 호출처럼 모델 밖의 행동을 수행하도록 연결합니다. |
| 메모리의 역할은? | 대화나 작업의 관련 상태를 저장·검색해 여러 단계 또는 여러 상호 작용에서 활용하게 합니다. |
| 오케스트레이션이란? | 모델·도구·메모리·작업 단계를 순서와 조건에 따라 조정하는 것입니다. |
| RAG의 목적은? | 외부 자료를 검색해 모델의 컨텍스트로 제공하여 최신성·근거·업무 지식을 보완하는 것입니다. |
| 환각이란? | 모델이 사실이 아닌 내용을 그럴듯하게 생성하는 현상입니다. |
| 비결정성이란? | 같은 질문도 설정·컨텍스트·상태에 따라 결과가 달라질 수 있는 특성입니다. |
| 모델의 최신성 한계는? | 학습된 지식이나 제공된 컨텍스트가 최신 업무 정보를 포함하지 않을 수 있다는 뜻입니다. |
| 사람 검토가 필요한 경우는? | 잘못된 결과의 영향이 큰 결정, 근거가 불분명한 답변, 개인정보·권리·금전과 관련된 업무 등입니다. |
| 모델 선택 시 보는 조건은? | 작업·모달리티·품질·언어·비용·지연 시간·보안·규정 준수·운영 조건을 함께 봅니다. |
| 모델 지표와 비즈니스 지표를 함께 보는 이유는? | 모델 답변 품질이 좋아도 처리 시간·만족도·비용 같은 업무 목표가 개선되지 않을 수 있기 때문입니다. |
| Amazon Bedrock의 중심 역할은? | 여러 FM을 선택·호출해 GenAI 애플리케이션을 구성하는 관리형 플랫폼입니다. |
| Amazon SageMaker AI의 중심 역할은? | 데이터·모델 개발, 훈련·사용자 지정·배포·관리를 폭넓게 지원하는 ML 플랫폼입니다. |
| SageMaker JumpStart는 무엇인가요? | SageMaker AI에서 사전 훈련 모델을 찾아 실험·사용자 지정·배포를 빠르게 시작하도록 돕는 기능입니다. |
| Amazon Q는 무엇인가요? | 조직의 업무와 개발 작업을 돕는 생성형 AI 어시스턴트 제품군입니다. |
| Strands Agents와 AgentCore의 차이는? | Strands Agents는 에이전트 개발 SDK이고 AgentCore는 에이전트의 운영·연결·보호를 위한 관리형 기반입니다. |
| Kiro는 무엇과 구분해야 하나요? | 모델 실행·호스팅 서비스가 아니라 AI 지원 소프트웨어 개발 환경으로 구분합니다. |
| Provisioned Throughput은 언제 검토하나요? | 트래픽이 예측 가능하고 일정한 처리량·지연 시간 계획이 중요할 때 온디맨드와 비교합니다. |
| 리전 선택에서 확인할 것은? | 모델·기능 제공 여부, 데이터 처리 위치, 지연 시간, 가격·할당량, 규정 준수와 장애 대응입니다. |

## 한 장 요약

```text
입력
 └─ 토큰화 → 청킹·임베딩 → 벡터 검색 → 컨텍스트 구성 → 프롬프트
                                                   ↓
                                            FM/LLM 추론
                                                   ↓
                             텍스트·이미지·오디오·비디오 생성

모델만 응답 → 생성형 애플리케이션
모델 + 도구 + 메모리 + 오케스트레이션 → 에이전트

유창함 ≠ 사실성
큰 모델 ≠ 항상 최선
모델 지표 + 비즈니스 지표 → 실제 성공 판단

Bedrock: FM 활용 | SageMaker AI: 모델 개발
Amazon Q: 업무 어시스턴트 | AgentCore: 에이전트 운영 기반
```
